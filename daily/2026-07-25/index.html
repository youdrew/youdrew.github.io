05The Verge AI

Google Zero：搜索引流量协议崩塌

过去二十余年间，Google 与万维网之间维持着一种隐性互惠协议：Google 抓取并索引全网内容，作为回报，将海量搜索流量导向出版商与各类网站。这一机制虽让 Google 获利远超内容生产者，却支撑起了基于 SEO 与自然搜索的广告变现体系。如今这一平衡被打破，核心原因是生成式 AI 在搜索结果中直接呈现摘要与答案，用户无需点击原始链接即可获取所需信息。出版商方面监测显示，自然点击量已出现持续且显著下滑，部分依赖搜索流量的站点流量降幅可达两位数百分比。Google 仍保留抓取与索引能力，但"引流"这一回报环节正在弱化甚至消失，协议事实上坍塌为单向的数据汲取。这场变化影响深远：依赖搜索引流的媒体、内容农场、电商导购乃至本地服务网站，其商业模式被迫重构，要么接受流量衰减，要么转向直接付费合作、订阅或自有渠道获客，AI 时代下开放网络与平台之间的价值交换逻辑正被重新书写。

06Apple 机器学习

LEAD：打破长程推理中的不可恢复瓶颈

针对大语言模型在长程执行任务中不稳定的问题，研究团队通过可控的算法谜题实验发现，即便提供高层策略，过度分解仍会制造"不可恢复瓶颈"——即模型将任务拆得越细，少量关键步骤上的持续性错误就越难被后续步骤纠正，最终导致整个推理链崩溃。关键发现是长程任务中的错误分布高度不均匀，决定成败的往往只是少数几个"困难"步骤上的不可逆失误。为缓解此问题，论文提出LEAD方法，核心思路是在原子级分解的同时引入短程前瞻验证，并对验证信号进行聚合，使模型在执行每一步时能预判其对未来若干步的影响，从而更早发现并规避不可逆错误。实验显示，LEAD在保持任务可分解性的同时显著提升了长程推理的稳定性，为Agent及长链路AI系统的可靠性提供了新的解决路径。

10Ollama

Ollama v0.32.4 更新

Ollama 发布 v0.32.4 版本更新，重点修复多项稳定性与功能性问题，并强化 Agent 能力。在模型创建流程中，针对请求家族的 8-bit 量化场景，新增对 lm_head 的量化支持，同时为草稿模型输出头提供同等待遇，有助于降低显存占用并保持推理精度。服务端修复了并行调度（PS）中加载映射表的数据竞争问题，该问题可能导致调度器 map 异常崩溃，由 dhiltgen 提交。此外，加固了更新器与传输相关的多个 flaky 单元测试，提升 CI 可靠性。模型侧修正了 qwen3_5 的专家量化处理，并将 gate_up 打包算子合并为单次 kernel 启动，减少调度开销。Agent 模块新增权限技能加载机制以及 system prompt 控制命令，方便用户管理工具调用权限与系统提示。MLX 后端则保留已加载模型的内存常驻，避免重复加载带来的延迟。对本地大模型运行用户而言，此次更新主要带来稳定性提升、显存占用优化以及 Agent 工作流更细粒度的控制能力。
