10arXiv · 视觉计算MAGIC用模态注意力检测医学LMM幻觉

研究将医学大型多模态模型的幻觉检测表述为生成答案 token 时跨模态注意力权重分布不均。 方法使用基尼系数量化各层、各注意力头中的模态特定注意力集中度。 研究在幻觉响应中发现视觉与文本 token 之间的注意力质量存在统计显著的重分配。 研究利用这些特征训练逻辑回归分类器，并在两个医学大型多模态模型、三种医学成像模态上进行评估。 实验结果表明，该方法相较当代幻觉检测基线达到具有竞争力或更优的性能。

GitHub BlogGitHub介绍跨智能体复用技能指南

GitHub Blog介绍智能体技能是以SKILL.md文件为核心的版本化目录，用于记录可重复执行的任务及其适用条件。 智能体技能可以跨智能体共享指令，但运行所需的工具、凭据和权限仍由宿主环境提供。 GitHub建议让相关技能采用一致的数据平台访问路径，并通过清单选择Databricks或DuckDB适配器。 GitHub Actions中的验证器会返回PASS、FAIL或PARTIAL，并必须引用变更文件中的证据；该操作仅静态审查差异，不执行代码或测试。 GitHub演示工作流将block-on-fail设为false，使检查结果仅作建议；默认情况下，FAIL会令检查失败，并在该检查为必需时阻止合并。 智能体技能适合边界明确、可重复且受益于复用判断的工作；需要稳定接口、共享状态、审计轨迹、长期控制或模型外部权限的工作更适合应用程序。 技能清单可以选择DuckDB或Databricks，但不能安装DuckDB CLI，也不能授予数据库访问权限，相关配置由环境及其用户负责。 若检查必须阻止合并或部署，需要在代码仓库的规则中配置该要求。
