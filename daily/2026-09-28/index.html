04AI Hot（卡兹克）MIT用AI优化RNA疫苗配方实现室温稳定一年

MIT研究人员借助AI算法优化脂质纳米颗粒（LNP）的辅料配比，开发出一种耐热性显著增强的RNA疫苗配方。该配方可使疫苗在室温（约25℃）下稳定保存长达一年，或在37℃条件下保存约两个月，同时在小鼠实验中诱导产生的免疫应答水平与Moderna现行疫苗相当。在传统研发路径下，脂质辅料组合的筛选需要数月时间，而该AI算法仅凭少量实验数据便能快速收敛至最优解，将整体筛选周期压缩至几周，效率提升超过一个数量级。研究成果已发表于《Nature Biotechnology》。这一进展的核心意义在于破解了RNA疫苗长期面临的冷链依赖瓶颈——目前mRNA疫苗普遍需要-20℃甚至-70℃的超低温运输与储存，是其在中低收入国家、偏远地区及疫情防控应急中大规模分发的最大障碍。若该技术后续通过临床验证并实现量产，疫苗的全球可及性将获得实质性提升，分发成本与碳排放也有望显著降低。

05Hugging FaceHolo4发布：面向通用计算机使用智能体

Hugging Face 发布了 Holo4，这是一个面向通用计算机使用智能体（computer-use agents）的框架/模型。与常见的浏览器使用或工具调用类智能体不同，computer-use agent 旨在让 AI 像人一样直接操作桌面级通用计算环境，包括任意 GUI 软件、系统级操作以及跨应用任务流程，因此对模型的视觉理解、动作规划与长程推理能力都提出更高要求。当前主流的 computer-use 研究多依赖专有模型或闭源环境，Hugging Face 选择以开源形式发布 Holo4，意味着研究者和开发者可以在统一、可复现的条件下训练、评测并迭代通用 GUI 操作智能体。Holo4 的定位属于智能体基础设施层，向上对接各类应用场景（如办公自动化、RPA、跨软件工作流），向下为模型层面的视觉-动作对齐、轨迹数据合成与策略学习提供基准。其重要性在于：computer-use 被视为大模型从“对话”走向“执行”的关键路径，而开源框架的稀缺一直是该方向进展的瓶颈之一；Holo4 的发布有望降低研究门槛，促进社区在该方向形成可比、可迭代的技术路线，推动通用桌面智能体从 demo 走向更稳定、可规模化的产品形态。

09arXiv扩散模型反向过程一阶平稳性理论

近期有研究将优化与采样的联系拓展至一阶理论，专注于扩散模型反向过程的收敛性质。该工作的核心结论是：当正向扩散过程所对应的平稳势函数具备强凸性时，无论是过阻尼还是欠阻尼的 Langevin 随机微分方程反向流，都能以显式指数速率实现相对 Fisher 散度的收缩。强凸性这一前提仅取决于所选加噪过程的设计，而不依赖于真实数据分布本身，这是 SDE 类反向扩散区别于 ODE 类方法的关键优势，因为后者通常需要数据分布满足更强的条件才能保证收敛。在引入连续时间分析的同时，作者还考虑了离散化与误差分析，给出了从理论保证到可操作算法的完整路径。这一进展为扩散模型的采样过程提供了严格的一阶收敛保证，意味着只要加噪核设计得当，模型就能稳定高效地逼近目标分布，对提高生成质量与降低计算开销具有实际意义，也为后续基于 SDE 的生成模型设计与超参数选择提供了理论支撑。
