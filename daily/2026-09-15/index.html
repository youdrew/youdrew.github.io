02量子位分子之心QuantaMind登Science Advances，AI蛋白设计进入动态时代

08AI Hot（卡兹克）硅基流动开源 Hy4 preview：770B 参数、1M 上下文

硅基流动近日在其模型平台上线开源模型 Hy4 preview，采用 Apache 2.0 协议，允许商用与二次分发。该模型总参数量达 770B，但每 token 仅激活 49B，属于典型的混合专家架构路线，目标是在保持超大模型知识容量的同时，把单次推理的算力开销压到接近中小模型水平。Hy4 preview 支持 100 万 token 上下文窗口，可一次性处理长代码库、大型文档或多轮长对话记录，已在 Claude Code、Codex、Cursor 等主流编码与代理工具中完成接入测试。在定价上，平台给出每百万 token 输入 0.834 美元、输出 2.501 美元、缓存命中 0.042 美元的阶梯价格，与一线闭源大模型的同档服务相比整体偏低，且对缓存读取给予显著折扣，鼓励开发者在长上下文场景中复用历史 KV。综合来看，Hy4 preview 的关键意义在于把超长上下文、稀疏激活与开源可商用三者同时拉到主流可用水位，为编码辅助、研究分析、企业知识库等场景提供了一个成本可控、可本地化部署的备选方案，也可能加剧开源模型对闭源 API 价格体系的竞争压力。
