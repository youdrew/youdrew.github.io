06AI Hot（卡兹克）Google DeepMind 发布 Gemini 4 Neon

Google DeepMind 发布 Gemini 4 Neon，该模型主打前沿智能与快速端到端任务完成，覆盖软件工程、知识工作和科学工作流。 在 xhigh 思考级别下，Neon 在 Artificial Analysis 智能指数上得分 61，总排名第 3；在 Vals 指数上排名第 2，跻身帕累托前沿。 Neon 的定价为每百万输入 token 3 美元、每百万缓存输入 token 0.15 美元、每百万输出 token 15 美元，上下文窗口为 100 万 token。 Neon 可在单个 100 万 token 的上下文窗口中综合处理电子表格、PDF、图表、音频和视频等输入，并将其转化为结构化的交付成果。 在 Artificial Analysis Coding Agent Index 上，Neon 以 58.6 分排名总榜第一；在 Terminal-Bench 4.1 上得分 65.2%，在 FrontierCode 2.0 默认高设置下得分 46.2%。 Gemini 4 Neon 今天起在 Google AI Studio 的 Gemini API 中推出，同时上线 Gemini for business（通过 API 和模型下拉菜单提供），面向 Google Antigravity 中付费的 Google AI Pro 和 Ultra 订阅用户，以及 Gemini 应用中的 Pro 和 Ultra 订阅用户。 面向开发者，Neon 可在 Google AI Studio 和 Android Studio 中通过 Gemini API 付费层级进行构建；Google AI Pro 或 Ultra 付费订阅用户可在 Google Antigravity 中试用 Neon，所有 Pro 和 Ultra 订阅用户均可在 AI Studio 中试用。 Neon 的四个层级稳步递进，让团队能根据每项工作负载的需要调节智能水平和 token 开销。 在 Gemini 应用中，Gemini 4 Neon 擅长需要前沿级推理和快速响应的工作。 材料注明浏览器不支持音频元素。
