02AI Hot（卡兹克）

Anthropic称已基本解决提示注入攻击

Anthropic 工程师 Boris Cherny 近日表示，通过模型训练方法，Claude 在实际使用中面临的提示注入威胁已得到根本性缓解，其有效性接近"基本解决"。所谓提示注入，是指攻击者通过在输入中嵌入隐蔽指令，诱导模型执行非用户本意的操作，长期被视为大模型落地应用的主要安全风险之一。Cherny 强调，防御并非依赖单一手段，而是将模型层面的训练改进、针对输入内容的探测机制、以及用于判断操作意图的分类器叠加使用，形成多层防护体系。独立研究者开展的基准测试结果显示，在面对未出现过的间接提示注入样本时，攻击成功率可降至约 0%。此外，Anthropic 宣布旗下编程工具 Claude Code 的 auto 模式将于下周起默认开启，允许模型在用户监督下自主执行开发任务。这一进展意味着曾经严重制约 AI Agent 在企业环境中可靠执行邮件处理、网页浏览、代码编写等高权限操作的瓶颈正在被打破，为 Agent 进入金融、政务等对安全敏感的场景奠定了基础。

05The Verge AI

AI 检测器正制造新一轮信任危机

AI 内容检测工具本意是应对生成式 AI 带来的真假混淆问题，却在实际部署中引发了新的信任危机。多款主流 AI 检测器被反复证明无法可靠区分人类与机器写作，不同平台对同一文本的判定常常相互矛盾，甚至将非母语者、年轻学生等群体的正常作品大面积误判为 AI 生成。由于缺乏可解释机制，被标记的作者很难举证自证，导致教师以此为依据处罚学生、雇主据此拒绝求职者、平台据此下架创作者内容的案例不断出现。问题根源在于这类工具普遍基于统计特征和概率阈值，而非真正理解语言本身，既无法跟上模型迭代速度，也难以抵抗简单改写带来的规避。更值得警惕的是，检测器给出的"AI 生成"结论在许多场景中已被默认采信，形成了"算法即裁判"的权力结构，一旦失误，受害者往往缺乏救济渠道。这场危机的意义在于，它让社会第一次大规模看到：当一项不成熟的技术被嵌入教育、雇佣、内容治理等关键流程，其不准确性会直接转化为对真实个体的伤害，也迫使监管者和机构开始重新审视 AI 判定结果的法律地位与使用边界。

10Simon Willison

GitHub Models 服务已正式退役

GitHub 已正式完成 Models 服务的退役下线，该服务曾作为独特的聚合层，在 GitHub Actions 中提供跨多家大语言模型厂商的统一 API 及模型试玩工具。开发者 Simon Willison 因仓库工作流报错才注意到这一变更，其错误提示虽曾显示为临时不可用，实则服务已彻底终止。GitHub Models 的核心价值在于允许代码利用环境内已有的 GitHub API 密钥直接调用外部模型，简化了集成流程并降低了开发门槛。然而，随着该中立聚合层的移除，开发者现需自行对接各家模型提供商的接口并独立处理计费事宜。这一变动标志着 GitHub 在 AI 基础设施策略上的重大调整，迫使开发者回归分散式的模型接入模式，增加了集成复杂度与管理成本，也反映出平台在 AI 服务生态中角色定位的重新审视。
