06AI Hot（卡兹克） ＋3

通义千问开源Qwen3.8-Flash，Qwen4架构预览

通义千问近日开源发布 Qwen3.8-Flash，这是一款采用混合专家架构的多模态大模型，同时被定位为下一代 Qwen4 架构的早期预览版本，权重完全开放。该模型总参数量达 1250 亿，但每个 token 推理时仅激活约 60 亿参数，稀疏激活机制使其训练成本压缩至上一代 Qwen3.7-Plus 的九分之一，而官方公布的基准测试显示其性能在多项任务上全面超越前作，意味着效率提升并未以能力为代价。生产环境 API 定价为每百万输入 token 0.16 美元、输出 token 0.47 美元，原生上下文窗口为 262K tokens，并可通过技术手段扩展至 1M tokens。这一组合对开发者和企业部署长上下文多模态应用意味着显著降低的算力门槛与使用成本，其作为 Qwen4 前瞻的意义在于提前暴露下一代架构特性，可能为后续生态适配与社区微调提供基础，也反映出国内大模型在稀疏架构与成本控制上的持续推进。

10Google Research ＋1

GlucoFM：面向连续血糖监测的医疗基础模型

Google Research 发布医疗健康基础模型 GlucoFM，聚焦连续血糖监测（CGM）时序数据分析。该模型基于大规模 CGM 数据训练，旨在提取可迁移的通用表征，服务于下游血糖预测、异常事件检测等任务，是基础模型范式在医疗时序数据上的重要落地尝试。糖尿病管理长期依赖 CGM 设备持续采集数天到数周的高频血糖读数，数据维度高、个体差异大，传统机器学习方法往往需要针对单一任务和单一群体单独建模。GlucoFM 通过预训练—微调的思路，将分散的标注任务和患者数据纳入统一的表征空间，有望缓解标注数据稀缺、模型泛化能力不足等现实痛点，并支持个性化预测、餐后响应分析、低血糖预警等临床关注场景。该项目也反映出 Google 在医疗基础模型方向上的持续投入，结合此前 Med-PaLM、Med-Gemini 等多模态模型的工作，进一步推动通用 AI 能力向医疗专业场景迁移。
