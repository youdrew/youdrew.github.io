08AWS 机器学习AWS在EKS上扩展MoE强化学习吞吐提升40%

AWS 发布技术博客，介绍在 Amazon EKS 上扩展 Mixture-of-Experts（MoE）强化学习训练的架构方案，核心在于将 EKS 容器编排、Elastic Fabric Adapter（EFA）高性能网络与 DeepEP 通信库相结合，并复用 Amazon S3 作为可扩展的对象存储层，从而支撑大规模分布式 RLHF 与 GRPO 训练场景。该方案针对 MoE 训练中专家参数分散、节点间通信密集，以及 RL 流程中 rollout 与训练阶段反复切换带来的吞吐瓶颈，利用 EFA 绕过操作系统内核实现低延迟高带宽的网络传输，配合 DeepEP 优化 MoE 路由与跨节点 all-to-all 通信，降低专家调度开销，并通过 S3 实现 rollout 数据、检查点与中间结果的高吞吐存取。据 AWS 公布的数据，在大规模 RLHF 与 GRPO 训练负载下，聚合 rollout 吞吐量提升约 40%。这一方案的意义在于，原本需要专门自建集群才能跑起的 MoE 强化学习训练，可以以更接近托管服务的方式部署在 EKS 之上，降低了工程门槛，也使 RLHF 与 GRPO 这类对 rollout 效率敏感的训练范式更易于在生产规模上迭代，为基础模型的对齐与后训练阶段提供了更具性价比的基础设施选项。
