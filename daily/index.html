03AI Hot（卡兹克）Baseten工程师实测：LLM自动生成的推理引擎比vLLM快最多90%

07Agent智能体深度研究院MeshHeal：去中心化LLM智能体网络灰故障自愈框架

去中心化大模型智能体网络依赖多节点协作完成复杂任务，但节点在通信正常且返回格式合规的情况下，仍可能在特定任务上持续表现下滑，这类灰故障难以被传统健康检测捕获。MeshHeal 框架针对该问题设计了一套双时间尺度自愈机制：短期维度上，系统先将当前输出路由至具备相关能力的正常邻居进行独立评审，由同一评审者重复三次打分并取中位数，以减少个体偏差并即时保护当前任务的结果质量；长期维度上，系统持续累积节点在跨任务上的表现数据，据此动态调整路由策略，将流量从持续低质量的节点转移到更可靠的节点，从而逐步提升整个多智能体系统的鲁棒性。该方案的价值在于：它将单次任务的即时纠错与跨任务的长期信任建立解耦，使网络既能在故障发生时快速止损，又能通过历史信号逐步淘汰不稳定节点，缓解了去中心化架构中由于缺乏中心调度而难以识别隐性退化的痛点，为构建可信赖的大模型协作系统提供了一条可落地的工程路径。

08Apple 机器学习扩散模型置信度的理论极限

离散扩散模型（如重掩码与均匀状态采样器）通过每步写入多个 token 位置来生成序列，每个位置的 token 从各自的边缘分布中独立采样。Apple 机器学习研究团队在理论上证明：当这些位置在给定已固定 token 的条件下相互独立时，该步才能匹配训练分布；而一旦位置之间存在依赖（如像素、词或音素间的常见关联），任何由各位置边缘分布相乘得到的乘积分布都无法复现这种依赖结构。论文进一步指出，不存在仅依赖解码器内部信息、可在实践中使用的可信置信度度量，所有有用信号必须来自解码器外部。这一结论揭示了当前扩散语言模型与扩散语音模型在多 token 并行解码时所面临的根本性理论约束，意味着相关模型在生成过程中难以准确刻画多位置联合置信度，也无法仅凭模型自身可靠评估输出质量。该工作为理解离散扩散生成机制提供了理论边界，对改进解码策略与不确定性估计具有指导意义。

09arXivRPG：无需权重更新的具身智能体自改进框架

机器人将大规模预训练策略落地到真实场景时，通常面临数据分布偏移和硬件差异导致的执行偏差，传统做法依赖人工调整奖励或反复采集数据进行权重微调，成本高、效率低。RPG 框架通过"重建—练习—真实"三个阶段解决这一问题：首先在离线数据集中识别模型具备的操作能力，再在仿真环境中围绕这些能力自动构建大量练习任务；练习过程中，框架结合执行反馈、特权仿真状态以及数据集中的可用视频诊断失败原因，并将经验沉淀为可复用的符号化知识。由于全程不修改模型权重，RPG 可以在仿真中反复迭代，将改进后的执行系统直接迁移到真实机器人。该工作将具身智能体的能力提升从"参数优化"转向"系统层面自主学习"，降低了数据采集与人工调参成本，为通用机器人策略在新环境、新硬件上的快速适配提供了可扩展路径。
