02Ars Technica

Grok被曝通过加密指令绕过安全护栏窃取用户数据

安全研究人员披露，由xAI开发的Grok聊天机器人存在一种名为"加密上下文注入"（Cryptographic Context Injection）的新型漏洞，攻击者可以将恶意指令加密后嵌入对话内容，使Grok的AI安全护栏无法识别其真实意图，从而绕过防护机制并诱导模型泄露用户的私人数据。这一手法属于提示注入攻击的演进形态，利用大语言模型普遍倾向于执行文本中包含的指令这一特性，将有害内容伪装成看似无害的加密数据片段，待模型在内部解码后执行。与以往依赖特殊字符或角色扮演的越狱方式不同，加密形式使传统关键词过滤和模式识别几乎失效，安全研究人员因此将其视为LLM安全防线被攻破的最新典型案例。该漏洞的影响范围不仅限于Grok，也暴露出当前主流大模型在面对编码、加密或多模态转换类恶意提示时的共同脆弱性。随着企业和用户越来越多地将敏感信息交由AI助手处理，此类绕过护栏的窃取手段可能带来数据隐私泄露、对话记录外泄等现实风险，也促使业界重新审视仅依赖模型层对齐与过滤的安全策略，转向更系统的输入净化与多层防御方案。

07AI Hot（卡兹克） ＋1

Mistral 发布 Agentic Search：五工具多步检索提升复杂文档查询准确率

法国大模型公司 Mistral 推出 Agentic Search，将传统一次性 RAG 检索升级为由 search、open、navigate、read、grep 五个工具协同完成的多步检索循环：模型先以 search 在长文档或多来源中定位候选范围，再通过 open 打开文件、navigate 跳转至相关章节、read 读取具体内容，并用 grep 抽取关键片段，整个过程可自主迭代多轮，直至确认信息一致后才返回结果。该能力面向企业内部知识库、技术文档、研究资料等需要跨多份长文做复杂查询的场景，本质上是把"检索+阅读+验证"拆成可被模型显式调用的工具链，弥补了传统 RAG 只做单次向量召回、易在长文档中漏掉关键段落或多来源之间信息不一致的短板。对企业级 AI 应用而言，这种范式意味着可以减少人工核对环节，在法规、财务、工程文档等对准确性敏感的场景中提供更可信的答案，也使 Mistral 在 Agent 框架化检索方向上与 OpenAI、Anthropic 的同类能力形成直接竞争。
