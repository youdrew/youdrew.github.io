08AI Hot（卡兹克）Agent长任务上下文工程：四类机制对抗上下文溢出

在长任务执行场景下，大语言模型驱动的 Agent 普遍面临两大难题：上下文窗口容量有限导致的信息溢出，以及多轮交互后原始任务目标逐渐被遗忘。AI Hot 的分析指出，Agent harness 层作为 Agent 与模型之间的中间件，是解决这些问题的关键工程层，其应对机制可归纳为四类。第一，上下文预算与卸载，即预先估算每一步的 token 消耗，将暂时不用的信息从上下文窗口中移出，需要时再按需加载，从而为主对话保留充足空间。第二，压缩，对历史对话进行摘要或精简，把冗余内容压缩为短表征，在保留语义的前提下大幅减少占用的 token 数量。第三，todo-state 复述，在关键节点将当前任务目标和已完成步骤重新注入上下文，相当于给 Agent 做"记忆校准"，防止目标漂移。第四，跨会话记忆，将关键状态持久化到外部存储，使 Agent 在会话之间也能延续任务进度。这四类机制为构建可在真实业务中长时间稳定运行的智能体系统，提供了可参考的工程路径。
