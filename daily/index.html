03arXivROBORMBENCH：视觉语言奖励模型的释义脆弱性

视觉语言模型（VLM）正被广泛用作机器人学习的奖励函数，但这一应用依赖一个基本前提——释义不变性，即对相同目标的不同表述应给出相同的进度评分。该研究系统揭示了当前 VLM 奖励模型并不具备这一性质：仅对指令进行改写而不改变机器人实际行为，预测的进度分数就会出现显著波动，同一轨迹甚至可能在"成功"与"失败"之间反复翻转。为量化该失效模式，作者构建了 ROBORMBENCH 基准，包含 2390 条真实机器人轨迹、配有真实进度标签以及 21 种指令释义方式。基于该基准的实验表明，多个主流 VLM 奖励模型的一致性明显不足，在不同释义下评分差异显著，甚至与人工标注的真值进度产生系统性偏差。这一发现意味着，即便机器人执行完全正确的动作，只要指令措辞变化，训练信号就可能被严重扭曲，进而影响策略学习的稳定性与可靠性。该研究提示业界，在将 VLM 作为机器人奖励来源时，必须引入释义鲁棒性评估，否则下游策略可能学到错误的反馈信号。

06Nature Machine IntelligenceNucleicBERT：通过自监督语言建模解读RNA序列空间

Upadhyay等人针对非编码RNA结构与功能注释稀缺这一长期挑战，开发了名为NucleicBERT的自监督学习模型，并在Nature Machine Intelligence发表相关研究。该模型借鉴自然语言处理中BERT的掩码语言建模思路，在大规模未标注的非编码RNA序列上进行预训练，仅依靠序列本身蕴含的统计相关性，而非任何功能或结构标签，即可学习到与RNA生物学相关的隐含表征。由于RNA二级结构与功能往往由局部与全局的序列上下文共同决定，掩码预测任务迫使模型捕捉碱基共变、配对倾向以及长程依赖等模式，从而在下游任务中迁移为对结构基序、折叠倾向和功能类别的判别能力。研究显示，该方法在多个RNA结构与功能基准上优于或接近依赖标注的传统监督方法，并显著降低了对昂贵实验注释数据的依赖。这一思路将NLP领域的自监督范式拓展到生物序列，为RNA组学、RNA药物靶点发现以及非编码基因功能挖掘提供了可扩展的新路径。

07Nature Machine Intelligence量子神经算子以隐式二次框架突破经典线性容量限制

Wang等人在Nature Machine Intelligence上发表了一种面向硬件的量子神经算子，旨在解决高维偏微分方程。传统量子与经典神经算子在用算子学习逼近解映射时，表达能力受限于线性容量瓶颈，即参数增长难以换来对复杂函数族的有效覆盖。该工作的关键创新在于引入"隐式二次框架"，在量子线路中以隐式方式构造出相对于输入特征的二次依赖结构，使模型在保持参数相对可控的同时，突破原有线性表达上限，从而获得对复杂微分算子的更强拟合能力。作者还针对当前含噪中等规模量子（NISQ）硬件的约束设计了硬件高效线路，控制了线路深度与门数，使方法在真实量子设备上具备可行性。该成果的意义在于：它把量子机器学习从以往主要停留在理论表达性优势，推进到与NISQ硬件现实结合的算子学习层面，为高维偏微分方程的量子加速求解提供了一条可工程化探索的新路径，也为后续量子-经典混合算子学习方法建立了可参照的设计范式。
