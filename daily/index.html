Claude CodeClaude Code v2.1.299 变更与修复版本进展 · 10 条

新增 CLAUDE_CODE_DISABLE_FILE_MENTIONS 环境变量：Claude 仅获取 @ 文件提及的路径由其文件工具读取，而不是文件内容。 新增终端空闲压缩：超过 200K token 的对话在闲置约 54 分钟后会被压缩，赶在一小时提示缓存过期之前。 新增 --shutdown-drain-sec 选项给 claude self-hosted-runner orchestrator：收到 SIGTERM 时停止轮询，并给正在进行的轮询和运行中的 spawn 钩子最多这么多秒时间完成。 在 mod 的 Text 中添加 size、weight、mono 和 tabular，在 Box 中加入 xs 到 xl 的命名间距步骤；bold 已弃用，由 weight 取代。 在 agent 视图中新增 /effort 和 /fast，用于设置新会话启动时的参数。 空闲压缩的 200K token 最低阈值可通过 CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS 调整；也可在 settings.json 中设置 "idleCompaction": false 来关闭，且两者都需要 v2.1.290 或更高版本。 新增 $.prompt.media，供通过托管设置安装的 mod 的 prompt.submit 钩子读取附加在提示上的图片或文档的字节。 新增 $.session.identity()，供通过托管设置安装的 mod 使用：当会话以托管方式登录时，可获取会话登录方式，以及其组织和邮箱（当 forceLoginOrgUUID 列出该组织时）。 mod 的 skill.prompt 钩子现可接收该技能的 frontmatter、source、插件名称和文件路径。 修复：脚本中运行时构建的、且 Claude Code 无法读取的 rm，除非设置 CLAUDE_CODE_STRICT_INLINE_SHELL_RM_PROMPT=1，否则不再提示。 修复：全屏模式下双击已展开记录行中的单词会折叠该行，而非选中该单词。 修复：claude mcp list、claude doctor 和 /status 将空的 .mcp.json 报告为无效的问题。 修复：在全屏模式下向上滚动时使用 /btw 会把记录跳到底部的问题。 修复：在沙箱可写入 Windows 驱动器的 WSL2 上，沙箱化命令因 bwrap: Can't mkdir /mnt/c/Program Files/ClaudeCode 而失败的问题。 修复：在 Agent SDK、IDE 和 claude remote-control 会话中，后台任务运行时定时唤醒（ScheduleWakeup）不触发的问题。 修复：对于某些带有粘贴图片或无法读取图片的提示，mod 的 prompt.submit 改写会被静默丢弃、按原样发送的问题。 修复：同一批次的另一个排队提示交付失败时，导致一个 Remote Control 提示丢失的问题。 修复：已通过钩子的 Remote Control 提示在 Stop 中断下一个排队提示的钩子时被从提示历史记录中丢弃的问题。 修复：在 Linux 上，沙箱化命令在配置目录留下空的 .config.json 后，登录、MCP 服务器和项目信任看似丢失的问题。 修复：当项目文件夹不可写导致设置无法保存时，/sandbox 仍报告成功的问题。

指南介绍四种为 Copilot 定制项目上下文的方式：自定义指令传递项目约定、智能体技能封装可复用的流程、自定义智能体应对更大专项任务、模型上下文协议（MCP）服务器连接外部工具与数据。 仓库级自定义指令通过 .github/copilot-instructions.md 文件定义架构、命名规范、测试与验证预期等指南；也可在 .github/instructions 创建带 applyTo 字段的路径特定指令文件，匹配的文件可同时使用全局与专项指令。 智能体技能是包含指令与可选脚本的文件夹，可放在 .github/skills 下各自的子目录，例如 .github/skills/quality-checks 内的 SKILL.md 说明何时调用技能、运行哪些测试与 lint 脚本及其作用和故障排查方式。 自定义智能体的仓库级配置文件位于 .github/agents，可定义智能体的用途、指令、工具和相关项目上下文，用于跨多文件并涉及多种工具与上下文源的重复性任务。 MCP 服务器（如 Playwright）让 Copilot 可在浏览器中打开并操作应用以验证更新后界面表现；用户也可在 Copilot 应用中浏览可用 MCP 服务器或添加自定义服务器。 自定义指令仅作为协作约定与流程基线，本身不等同于完成实际修改。 智能体技能仅在 Copilot 执行运行质量检查、准备发布、调试失败工作流等特定流程时被加载。 自定义智能体常用于类似无障碍审查等需要跨多文件检查组件、模板、样式与交互的更大型任务。 MCP 服务器（如 Playwright）的作用是验证界面行为是否符合预期，覆盖范围超出仅通过自动化检查。
