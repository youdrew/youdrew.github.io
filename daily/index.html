LMSYS 在 H20 上优化 DeepSeek-V4-Pro，性能逼近 B300

LMSYS 团队近日针对参数量达 1.6 万亿的混合专家模型 DeepSeek-V4-Pro，在单节点 H20-141GB GPU 上完成了推理性能优化工作，相关成绩在社区引发关注。该团队并未更换硬件，而是通过场景化的服务配置调优，包括推理参数、显存调度与服务端策略的协同调整，使受限硬件环境下的输出吞吐提升至每秒 271 个生成 token。作为对比，旗舰级 B300 GPU 在相同模型下的参考成绩为每秒 383.7 个 token，两者差距被压缩至约 1.42 倍，意味着仅凭中端推理卡配合精细工程化优化，就能逼近顶配硬件绝大部分的吞吐表现。这一结果对大模型低成本部署具有现实意义：它说明在算力受限或采购受限的场景下，通过软件栈与配置层面的深度打磨，可以在不依赖最尖端硬件的前提下运行超大规模模型，为企业及研究机构提供了一条更具性价比的工程路径，同时也凸显出推理优化在 AI 基础设施竞争中的关键地位。

SPADE：自适应合成可执行环境中的自博弈框架

在语言智能体持续自我改进的训练范式中，传统环境池——无论是人工整理、静态合成还是基于冻结验证器——都存在目标分布固定的问题，难以随学习者能力扩展而动态调整，制约了开放式技能习得。SPADE（Self-Play in Adaptive Synthetic Executable Environments）提出一种自博弈强化学习框架，让同一个大语言模型同时承担两个角色：环境设计者以可执行代码形式撰写具备 reset()/step() 接口的完整长视野训练环境，求解者则在这些环境中学习推理与决策。由于环境本身由代码生成且具备自适应扩展能力，目标分布可在训练过程中持续多样化，打破了静态环境的瓶颈。该框架的意义在于为语言智能体提供了一条无需人工设计新任务即可实现开放式能力增长的路径，使单一模型在环境生成与策略优化之间形成闭环，是迈向可扩展自我提升智能体的重要一步。

ADEPT：利用预训练与强化学习后训练加速灵巧操作

ADEPT 是由研究者在 arXiv 上公开提出的机器人灵巧操作学习框架，聚焦于解决复杂操控任务中样本效率低、训练成本高这一长期制约具身智能发展的核心难题。该方法将大规模预训练与强化学习后训练阶段相耦合：先借助预训练让策略获取对物体动力学与接触交互的通用先验，再通过针对性的强化学习后训练使策略适配具体灵巧操作任务，从而避免从零开始探索高维动作空间。在传统方法往往需要海量交互且难以稳定收敛的情况下，ADEPT 通过两阶段衔接显著降低了对真实环境交互量的依赖，并提升了最终策略在精细操作任务上的表现。该研究既为机器人操控社区提供了一种兼顾效率与性能的实用训练范式，也对推动具身智能从感知理解走向可落地灵巧执行具有参考意义，其思路有望迁移至更广泛的接触密集型机器人任务中。

10Claude Developers (X) ＋1

Claude Code 新增 Concise 输出风格

Anthropic 为其面向开发者的命令行工具 Claude Code 推出了一项名为 Concise 的输出风格设置，允许用户在交互过程中使用更加精简的回复模式。开启后，Claude 会优先呈现最终结论或结果，而将实现细节、推理过程等背景信息默认隐藏，只有当用户主动追问时才会展开完整说明。该功能可通过两种方式启用：一是进入 Claude Code 交互界面运行 /config 命令，从 Output style 选项中选择 Concise；二是直接在项目的 settings.json 配置文件中将 outputStyle 字段设为 "Concise"，便于在团队或自动化场景中统一配置。此举针对的是开发者在使用 Claude Code 协助编码、调试和排查问题时常见的"信息过载"痛点——在多数日常交互中，开发者真正需要的是快速可用的答案，而非冗长的解释。Concise 模式通过让模型"先给结论、按需展开"，降低了逐条翻阅输出的认知负担，加快了决策节奏；同时，可选展开的能力又保留了复杂任务下获取完整推导路径的通道，兼顾效率与透明度，对高频使用 AI 编程助手的工程师而言具有较高实用价值。
