03The Verge AI加州收紧AI数据中心能源与用水监管

05微软研究院微软RetroChimera模型加速小分子合成预测

在医药、材料和农业等领域，定向合成新分子的需求持续增长，但传统合成路线高度依赖化学家的经验和反复实验试错，研发周期长、成本高，成为制约定制分子创新的核心瓶颈。微软研究院在《Nature》上发表论文，推出专门用于小分子逆向合成路线预测的模型 RetroChimera，目标是让研究人员能够以更高准确率、规模化地预测从小分子前体到目标产物的可行合成路径，从而加速对广阔化学空间的探索。该模型借助机器学习对大量已知合成反应数据的学习，可在短时间内给出多条候选路线及对应前体，辅助化学家快速筛选与优化方案，减少不必要的湿实验投入。其意义在于把合成规划从以人工经验为主的工作流，转向由模型驱动的可计算环节，使药物候选分子、新材料或农用化学品的设计与制备迭代更高效；同时也让缺乏资深合成经验的研究团队能够更平等地参与到分子创新中，推动化学研发整体的提速与降本。

09Hugging FaceHugging Face 发布 tokenizers v1：Rust 核心、Python 统一接口

Hugging Face 正式发布 tokenizers v1，这是该分词库自 Rust 核心与多语言绑定拆分以来的首个里程碑版本。tokenizers 最初作为 Transformers 生态的一部分发布，后因其 Rust 实现的高性能被独立成库，并陆续提供 Python、Node.js、Rust 等多语言绑定，但各绑定之间的 API 和行为一致性长期是开发者的痛点。v1 版本的核心改动是把 Rust 实现与多语言绑定整合为统一版本，在 Python、Node、Rust 等接口下提供一致的 encode、decode、词表加载和特殊 token 处理 API，并稳定了分词流程中归一化、预分词、后处理等模块的默认行为。在官方基准测试中，新版本在批量分词场景下保持了原有的线性扩展性，单线程吞吐量与上一稳定版持平，多线程条件下 CPU 利用率更稳定。tokenizers 库被广泛用于 Transformers、Datasets 以及大量生产环境的文本预处理流水线，v1 的统一接口降低了多语言项目接入和维护成本，对使用 Rust 端到端构建 NLP 推理服务、或在 Python 与 Node 环境间共享同一分词逻辑的团队有直接价值，同时为后续稳定迭代提供了基线。
