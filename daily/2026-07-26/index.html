xAI 发布 Grok CLI 并支持 /tutorial 命令

xAI 近日推出名为 Grok CLI 的命令行工具，面向已下载 Grok Build 的用户开放，使用时只需在终端输入 /tutorial 指令即可启动交互。Grok 是 xAI 推出的大语言模型，此前主要通过网页、API 以及 X 平台等渠道触达用户，此次发布的 CLI 版本将交互场景延伸至本地终端，使开发者可以在不打开浏览器的情况下直接调用模型完成问答、代码生成与脚本辅助等任务。与 ChatGPT、Claude 等竞品已陆续推出的命令行客户端相比，Grok 此前在开发者工具层面的覆盖相对薄弱，CLI 的补齐意味着 xAI 开始系统性地布局面向工程师群体的接入路径，进一步扩展 Grok 在自动化工作流、CI/CD 脚本与本地开发环境中的使用空间。由于目前该功能以 /tutorial 形式呈现，更像是早期试用入口而非完整产品，xAI 后续是否会开放更丰富的子命令、参数配置以及 API 密钥管理，仍有待观察，但这一动作本身已显示出 xAI 在开发者生态建设上的加速意图。

03Hacker News

Android或将限制设备本地ADB权限

Android 平台上长期作为开发者与高级用户核心工具的 ADB（Android 调试桥）功能，正面临权限收紧的可能。这一动向源自近期 Hacker News 上一则引发广泛讨论的帖子，截至发稿已获得 854 分和 402 条评论，热度持续攀升。ADB 因允许用户在本地直接执行设备调试、应用安装、系统文件修改等高权限操作，一直是刷机玩家、定制 ROM 社区以及安全研究人员的常用工具。若 Android 后续版本对其施加更严格的本地调用限制，意味着用户在未连接开发主机或缺乏特定授权的情况下，可能难以再像过去那样自由调取调试接口，这将对依赖 ADB 完成系统定制、应用逆向和底层问题排查的群体产生直接影响。社区讨论焦点集中在权限边界如何划定、是否影响 USB 调试模式，以及普通消费者设备是否会同步收紧等多方面议题。考虑到 ADB 在 Android 生态中的基础性地位，相关政策若最终落地，将重新定义开发者和高级用户对设备底层功能的可触及范围，并可能进一步收窄长期以来相对开放的 Android 可玩性空间。

IIHS研究：Waymo自动驾驶出租车事故率比人类低68%

美国公路安全保险协会（IIHS）基于2021至2024年美国联邦政府自动驾驶事故报告数据，发布了一项针对Waymo自动驾驶出租车的安全性研究。结果显示，Waymo的事故发生率比人类驾驶员低68%，且在事故严重程度方面也明显更轻。这项研究在时段背景上具有特殊性：由于竞争对手Cruise于2023年停止运营、Zoox直到2025年才向公众开放载客、特斯拉的奥斯汀Robotaxi数据未被纳入统计，因此Waymo几乎成为唯一可供分析的大规模对象。截至目前，Waymo已在美国11座城市运营自动驾驶网约车服务，覆盖面积超过罗德岛州，累计完成数千万次载客。需要指出的是，Waymo的运行依赖于L4级自动驾驶技术和高精度地理围栏，这意味着其低事故率是在限定区域和特定条件下取得的，尚不能直接等同于全场景、全天候的自动驾驶安全水平，该结论仍需审慎解读。

10Simon Willison

Ruff v0.16.0 默认启用413条规则

Astral 于 7 月 23 日发布 Ruff v0.16.0，这是其 Python 静态检查工具一次影响范围较大的 linting 行为变更。该版本将默认启用的规则数量从 59 条大幅提升至 413 条，整体规则库也从 708 条扩展到 968 条，原因是 Ruff 的默认规则集自 v0.1.0 之后便未再调整，此次收录了长期以来未默认启用、但能捕获语法错误和即时运行时错误等严重问题的若干规则。由于新默认检查被直接启用，加上许多项目在开发依赖中使用的是未固定版本号的 "ruff"，大量 CI 流程在升级后立即出现构建失败。对于依赖 Ruff 保障代码质量的团队而言，这次变更意味着需要尽快固定 ruff 版本至 v0.16.0 之前的稳定版，或主动审查并适配新增的默认规则集，以避免持续集成流水线中断。
