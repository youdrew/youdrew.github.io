03Agent智能体深度研究院

浙大TokenPilot：保持缓存命中的Agent上下文管理，省87%成本

浙大团队在 EMNLP 2026 上发表的 TokenPilot 论文，针对大模型 Agent 在长任务场景下的上下文管理难题提出新解法。传统做法是在 token 数逼近上下文窗口上限时，对历史工具调用、对话记录做压缩或截断，但研究者指出这一思路忽略了 prompt cache 的前缀连续性约束：一旦被丢弃的内容位于缓存前缀范围之外，后续请求就会触发整段前缀的重计算，由此产生的算力开销往往超过压缩所节省的 token 费用，得不偿失。为此，TokenPilot 将 token 级压缩与缓存感知调度耦合，在每一次上下文更新时同时计算压缩收益与缓存命中率变化，优先选择既缩短输入又不会打破 cache 前缀完整性的策略。实验显示，在长时间 Agent 会话场景下，该方法可实现整体成本下降约 87%。这一结果的意义在于，它把缓存机制从底层工程细节提升为上下文管理的显式约束变量，为后续 Agent 系统在效率与推理经济性之间取得平衡提供了一条可复用的设计路径。

可读性≠可解释性：思维链推理中判断与实际重要性的对比

一项针对思维链（chain-of-thought）推理可信度的研究指出，尽管大语言模型生成的推理过程看似清晰可读，但其语句的"重要性"未必与对最终答案的因果贡献一致。研究团队设计了一类干预实验：直接扰动或替换推理中的关键步骤，观察模型最终输出是否随之改变，从而衡量各步骤的真实因果权重。结果显示，人类及LLM评委在标注"重要步骤"时，往往倾向于选择叙事流畅、语义突出的句子，而非真正决定答案走向的内容；某些被评委高度评价的推理环节在因果干预下对结果几乎没有影响，而一些看似平凡的中间步骤却承担了关键作用。这一发现意味着，仅凭表面可读性来评估模型的忠实性、诊断错误或进行逐步监督存在系统性偏差，可能误导对模型推理能力的判断，并影响下游的可解释性研究、模型调试与安全审计实践。

09arXiv

黑箱LLM评判器稳定性审计：预注册可靠性研究失败

研究针对大语言模型作为评判器时的一项被普遍忽视却至关重要的假设——同一请求发往同一模型名应返回稳定结果——进行了预注册审计。所谓预注册，是指研究者在实验前就将所有统计阈值与分析流程锁定并公开，从而排除事后调整。研究设计了两轮独立实验，事先设定仪器验证阈值，但均未达标：第一轮同一窗口内的重复排名 Spearman 相关系数仅 0.400，远低于 0.90 的合格线；第二轮跨日完全相同的请求回放，结果仅 0.78 的字节级一致率，同样低于 0.99 的预设要求。整个审计基于 52,988 次请求尝试完成，样本规模足够支撑结论的统计效力。这意味着，同一模型在不同时间点对同一输入可能给出显著不同的评分或排名，从根本上动摇了 LLM judge 作为稳定测量工具的可信度。这一发现对当前 AI 行业的多项核心实践构成直接挑战：依赖 LLM 评分筛选训练数据的 RLHF 流程可能引入大量噪声而难以复现；以 LLM judge 打分排序的各类模型排行榜，其排名波动未必反映真实能力差异，可能只是测量本身的抖动；学术评测与工业 A/B 测试若未控制评判时间窗口，结论的可靠性也会受到质疑。研究的更大价值在于示范了"把 LLM 当作科学仪器前必须先校验仪器"的审慎路径，对建立可复现的 AI 评测标准具有方法论层面的警示意义。
