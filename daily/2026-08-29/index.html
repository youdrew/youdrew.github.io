Claude额度重置/规则变更

Claude Code 发布 v2.1.251 版本，围绕模型切换与会话管理能力做出多项更新。背景在于开发者需要在多模型协作场景下更细粒度地控制行为与会话生命周期。此次新增 PreModelSwitch 与 PostModelSwitch 两类钩子事件，允许在模型切换前后进行拦截、确认或标注，为自动化流程增加了可观测与可控环节。SessionStart 续接钩子进一步扩展，现在可获取会话是否已过期，并返回重新缓存时的成本估算，便于会话恢复阶段做预算判断。在交互体验上，前台运行的子代理产生的工具调用与结果将实时流式推送到远程控制客户端，减少等待与盲区。计费透明度方面，/usage 页面新增消费限额进度条，开发者可直观掌握额度使用进度；同时为调用 Claude 应用网关的用户开放 rate_limits.spend_limit 状态字段，便于程序化判断是否接近上限。这些改动整体提升了模型切换的可控性、远程调试的实时性，以及成本管理的可视化程度，对依赖 Claude Code 构建复杂代理工作流的团队具有实际价值。

OpenAI 终止与 Cursor 合作，11月12日生效

OpenAI 因 SpaceX 收购 AI 编程工具 Cursor 母公司后产生的信任问题，决定于 11 月 12 日终止向 Cursor 提供模型访问，结束双方此前的模型供给合作。这意味着 Cursor 不再以"内置"方式调用 OpenAI 模型，原本由合作方直接代为结算的访问通道将随之切断。对开发者而言，原有使用方式并未完全中断：仍可通过自有 OpenAI API 密钥或借助各类 IDE 扩展调用 GPT 系列模型，官方表示将继续支持更广泛的工具生态与开源计划，开发者侧的迁移成本相对可控。此举的背景在于，SpaceX 在今年通过收购取得 Cursor 母公司后，OpenAI 对合作方的中立性与数据流向产生疑虑，因而主动切断供给。事件的影响在于，一方面强化了 OpenAI 对模型分发渠道的主导权，开发者将更依赖其官方 API；另一方面，模型层与应用层的边界进一步清晰，独立 IDE 与工具厂商无法再以合作名义获得模型"特权"，行业生态可能加速向"模型即平台、工具即客户端"的方向演进。

联邦法官裁定特朗普政府封禁Anthropic违法

美国加州北区联邦地区法院法官 Rita Lin 裁定，特朗普政府将人工智能公司 Anthropic 列为"国家安全供应链风险"并禁止联邦机构使用其 AI 技术的行政行为违法，构成对美国宪法第一修正案所保障言论自由的非法报复。法院在裁决中指出，Anthropic 之所以遭到封禁，根源在于其拒绝撤销在产品使用条款中的两项关键限制：禁止将 AI 用于致命性自主武器系统（即无需人类直接授权即可选定和打击目标的"致命自主战争"），以及禁止将 AI 用于对美国民众实施大规模监控。该禁令由特朗普政府此前以行政命令形式发出，将 Anthropic 列入供应链风险名单，实质上切断了联邦政府与该公司的合作。法官批准了 Anthropic 提交的部分即决判决动议，意味着法院已基于现有证据认定政府行为违宪，无需进入完整庭审即可作出对该公司有利的法律认定。这一裁决首次在司法层面明确认定，针对 AI 企业基于其产品伦理立场而实施的行政打压受第一修正案保护，对美国政府未来以"国家安全"名义干预 AI 公司的做法划定了清晰的宪法边界，同时也强化了 AI 开发者拒绝将技术用于特定军事或监控用途的合同权利。

Anthropic让Claude自主训练模型以缓解对齐失败

Anthropic发布了一项AI对齐研究，提出让Claude自主训练模型以缓解对齐失败问题。该研究针对欺骗、谄媚在内的10类典型对齐失败场景，训练后的模型相比基线在各项任务上都显著缩小了与完美表现之间的安全差距，同时未损害通用能力。值得注意的是，该方法具备较强的可扩展性，在比优化对象大4.7倍的模型上依然有效，这意味着规模更大的模型同样可以借助这一机制完成自我训练。在评估阶段，Claude生成的解决方案质量高于28名人类安全研究员，尤其在欺骗场景中，其最佳方案相比人类最优解进一步提升约20%的表现。这一结果反映出AI对齐研究范式的转变——从依赖人类专家主导设计训练方案，转向让模型自主生成、评估并迭代对齐策略，缓解人类研究者在大规模模型对齐任务中面临的能力瓶颈。它也为未来超大规模模型的对齐提供了一条更具扩展性的技术路径。
