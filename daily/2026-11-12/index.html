03AI Hot（卡兹克）Google发布Gemini Decisions API

Google 推出 Gemini Decisions API，由新模型 Gemini Decision 1 驱动，可在 150-250ms 端到端延迟内对文本、图像、音频、视频和 PDF（最多 256K tokens）一次性评估最多 1000 个是/否、多选和评分题。 你可以传入一个跨文本、图像、音频、视频和 PDF 的多模态输入（最多 256K token），以及最多 1,000 个独立问题。 Gemini Decision 1 无需逐 token 解码即可对选项打分，在多模态输入和最多 16K token 的上下文中，模型计算的中位延迟保持在 50-100 毫秒（端到端 150-250 毫秒），并且从每次请求 1 个问题到 100 个问题几乎保持平稳。 Decisions API 能在毫秒级判断意图，让日常查询的延迟最多降低 40%，同时把深度推理模型留给复杂任务。 Google Cloud 中的 Gemini 支持即将推出。
