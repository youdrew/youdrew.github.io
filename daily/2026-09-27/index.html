06Agent智能体深度研究院ACL26 亚马逊 SAGE：用强化学习训练 Agent 生成与复用技能库

亚马逊在 ACL 2026 上发表的长文 SAGE 提出了一个新框架，把可执行技能库直接接入强化学习闭环，让 Agent 在执行任务时自动生成、保存并跨任务复用技能。现有技能库方法多依赖提示词来调用，开放权重模型常常生成格式混乱、无法正确执行的低质量技能，且调用率低；同时，普通强化学习只奖励当前任务的最终结果，无法对跨任务技能复用这一中间行为给出有效激励。SAGE 的核心做法是：在 RL 训练过程中，Agent 会在多任务之间持续抽取可复用的执行步骤并写入技能库，下游任务再通过强化信号学会主动检索和组合既有技能，从而让"造技能"和"用技能"都获得可量化的回报。该工作首次把技能库构建、技能调用与多任务强化学习统一在同一目标下进行端到端优化，为开源 Agent 的自我改进和长期能力积累提供了一条可扩展的训练路径，也为评估 Agent 的技能抽象质量提供了新的实验基准。

10GitHub 新仓库Awesome Jev：TypeSafe AI 系统一模型资源列表

近日，GitHub 上出现了一个名为"awesome-jev"的新型 awesome-list 资源仓库，专门用于收录基于 Jev 构建的公开项目、集成方案与相关讨论。Jev 是 TypeSafe AI 提出的 System One 模型，其核心设计主张"带类型的决策"（typed decisions），即将 LLM 的输出与编程语言层面的类型系统挂钩，使模型生成的结构化结果能够被编译器或运行时直接校验，从而降低传统 prompt 工程中常见的字段缺失、格式错乱等失败率。该仓库本身不提供新算法，而是充当生态索引，把围绕这一范式形成的客户端库、框架插件、示例项目以及社区讨论集中归类，方便开发者快速复用现有集成并对比不同实现路径。从行业角度看，这类资源列表的涌现意味着带类型 LLM 调用正在从零散实验走向可共享的工程实践，而 System One 这类以类型约束为核心的系统级抽象，也为后续构建可验证、可组合的 AI 工作流提供了一条相对务实的工程路线。
