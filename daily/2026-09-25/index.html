06AI Hot（卡兹克） ＋1GitHub开源LLM驱动的C/C++模糊测试工具

GitHub Security Lab 近期开源了基于 Taskflow Agent 的 Fuzzing Taskflow，将大语言模型引入 C/C++ 模糊测试流程，由研究员 Antonio Morales 主导开发。该工具接受一个 GitHub 仓库链接作为输入，便会自动识别程序入口点（如 main 或被导出的 API），生成 fuzzing harness，再用 AFL++ 执行模糊测试，最后读取覆盖率报告并对触发到的崩溃进行分类与分诊，整个流程由 LLM Agent 在 Taskflow 框架下串联完成。Fuzzing Taskflow 的核心价值在于把过去高度依赖专家经验的工作——分析目标代码、编写 harness、解释覆盖率和崩溃——压缩为一次自动化运行，显著降低 OSS-Fuzz 接入与定制模糊测试的门槛，使中小型 C/C++ 项目也能以极低人力成本获得持续安全测试能力。其意义在于：当 LLM 已能可靠完成 harness 生成与崩溃分诊这类需要上下文推理的任务时，安全测试流水线中人力主要参与的环节被进一步压缩，长期可推动 C/C++ 生态整体安全姿态的提升，同时也凸显出 Agent 框架在重构传统安全工作流方面的潜力。
