05GitHub 新仓库dsh-go：手机运行并遥控DeepSeek

DSH Go 是基于开源 DeepSeek Harness 的第三方项目，运行在手机上的是 DSH 引擎，模型请求由用户配置的模型提供方处理。 本机运行可在 App 内安装 Ubuntu、Node.js 与 DSH 运行环境，无需 Root 或另装 Termux；远程连接可通过 SSH 或 DSHarness Remote 使用电脑、服务器上的 DSH。 DSH Go 支持切换模型、发送图片、使用语音输入、处理工具审批和提问，并提供聊天界面与网页模式。 项目开源并以 AGPL-3.0 发布，其中 sdk/ 和 examples/ 使用 MIT；DSH Go 的名称和标识以及 Deepy、鲸娘两位吉祥物不在开源授权范围内。 手机上装过签名不同的早期测试包时不能直接覆盖安装，需要先卸载旧版；卸载会清空对话、Linux 环境和设置。 DSHarness Remote 当前只支持图片附件，不能在 App 内打开网页版，插件管理限于开关，且不支持 DS Bot 和对话日志导出。 部分远程渠道需要在主机侧配置。 手机操控只对正常模式下的本机引擎开放，需要按界面说明开启无障碍等权限；不打扰模式另外要求 Android 14 及以上，以及 Shizuku 或自连 ADB。 开启手机操控后，任务需要的屏幕文字可能发送给模型，支持看图的模型也可能收到截图。 分享内容前需要检查预览，收到链接或文件的人可以保存其中的内容。 模型请求会发送给用户配置的模型提供方，需要联网，并按用户在提供方的账户计费。 重新解析 Ubuntu 软件包锁时还需要 gpgv。 运行时构建使用仓库固定的版本与校验信息，并需要联网下载依赖。 安装要求为 Android 8.0（API 26）及以上；arm64 安装包适用于常见的 64 位 Android 手机，x86_64 设备和模拟器使用 x64 包，仓库没有 32 位 ARM 构建。

08量子位Claude叫停Harness禁止逆向游戏改动

据量子位报道，Anthropic技术人员表示，他们在Opus 5.5模型的系统提示词里加了两句话，引导Claude不要去“重新创建一个属于别人的特定游戏”。 文章称，Anthropic给Claude Code增加的限制允许创建原创游戏、特定类型的游戏，以及使用用户自己的设计和素材制作的游戏，但禁止复刻已经存在的特定游戏，即使更改名称或称之为原创游戏也不行。 文章称，禁令出来没几天，Claude Code的GitHub issue页面就被刷爆了；一些完全原创的游戏开发在途中被Claude以“疑似在复刻现有游戏”为由停止，复现常见游戏机制或为桌游打补丁的请求也被拒绝。 文章称，独立游戏工作室“Alliance Arts”最近取消了其即将发布的新游戏《醉酒女神反流》的公开试玩。 “Alliance Arts”表示，他们担心有人把试玩版的内容喂给AI，用不了多久就能克隆一个出来，抢在他们的正式版发布前上线山寨品。 文章称，这项限制只管得了Claude自己；用户可以改用其他模型生成主要框架，也可以把具体且看不出上下文的技术任务交给Claude Code。 文章称，这项一刀切禁令还错杀了一大堆正常需求。 文章所述实验中，用户使用免费的Claude Opus 4.6模型，只用了一句提示词，不到两个小时便做出了一个功能完整、完全可玩的宝可梦克隆游戏。

09量子位西湖大学成立世界模型研究中心

西湖世界模型研究中心于10月31日在云谷校区成立。 西湖大学自主智能实验室AutoLab早在三年前开始研究世界模型，并孵化创业公司与企业界开展技术落地合作。 2024年底，AutoLab转向“概念世界模型”路线，不再生成像素，而是在抽象的数学隐空间中建立物理概念的表征。 研究进入到2025年，团队在实验中观察到，概念拆解与关联机制建立后，模型在复杂任务上的成功率较传统模仿学习与强化学习基线显著提升，同时保持较低的预测成本。 西湖数智Awomo于2026年初正式成立，定位为物理世界的基础大模型公司，目标是打造原生的物理大模型，而不只是给车企交付定制化解决方案。 Yann LeCun认为，单纯靠预测文本，AI永远无法触及人类级别的智能，需要能理解物理现实的模型。 于开丞表示，概念世界模型需要像人一样把复杂场景拆解成有限概念并重新组合，以“理解”训练数据中从未完整出现过的新场景。 材料指出，传统AI训练需要海量训练数据，这意味着极高的算力成本。 按于开丞的设想，依托通用物理基座，下游开发者或小企业可能不再需要采集百万级小时的数据，可能仅需20至30小时的后训练，即可快速定制特定领域的模型。 于开丞坚信，长远来看世界模型最终将服务于普通人的个性化创造需求。
