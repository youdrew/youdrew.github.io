07arXiv27B模型纯仿真训练可控制真实机器人

研究通过完全在仿真环境中进行强化学习且不使用示范数据，训练了一个27B开放权重推理模型，使其原生使用真实机器人。 该模型观察环境、进行思维链推理并生成下一末端执行器位姿，无需额外操作框架。 研究构建了面向智能体机器人后训练的PEAR，并以机器人使用强化学习RURL在规模化仿真机器人任务上训练模型。 在LIBERO和RoboDojo仿真任务上训练后，模型在真实双臂机器人试验中的成功率为60%，基础模型未成功。 在LIBERO-Pro中，π0.5在熟悉场景被分配新任务时仅0.75%的回合成功，该模型成功率为57.4%。 模型在推理、编码和视觉基准上没有可测量的能力下降。 目前强劲的机器人使用性能仅由GPT-6 Astra和Claude Fable 5.2等前沿专有模型实现，开放权重模型的能力仍明显较弱。

09AI Hot（卡兹克）TokenEconomizer开源插件降低编码Agent成本

UC Berkeley、Microsoft Research 与 Microsoft Security 发布开源插件 TokenEconomizer，从 Agent 在同一仓库的历史会话中学习，在不修改 Agent 或底层模型的情况下降低后续会话成本。 当一个代码库累计完成至少五个任务后，30% 的工具调用重复了该代码库中更早任务里的某个操作。 为用不上的工具付费。 综合来看，这些发现说明有效的成本控制必须因代码库而异，而不能到处套用同一种策略。 被移除的工具如有需要可以恢复。 它的设计目标是与现有 AI 编码智能体并行运行，无需修改其底层模型，自身也不需要 API 密钥，并且学到的内容都保留在开发者本机。

arXiv · 视觉计算面向大型视觉语言模型的上下文屏蔽后门攻击

研究者提出一种称为上下文剥离的现象：周围干净视觉令牌在完整长度下会抑制嵌入的触发器，而令牌剪枝移除该上下文后后门被激活。 作者提出 StripWake，这是一种仅作用于投影器的后门，在完整令牌审计下保持休眠，却能在未见过的压缩器上被激活。 在 LLaVA-1.5-7B 上跨九个未见压缩器测试，StripWake 的完整令牌攻击成功率为 0.4%，在五个主要压缩器上的压缩攻击成功率为 94.0%-99.7%，且没有 CIDEr 损失。 现有 LVLM 后门在出现触发图像时即发作，而此前的部署触发类攻击仅在模型权重被量化或剪枝时才激活。 常规 LVLM 后门在完整令牌推理下攻击成功率接近 100%，因而会在部署前审计中立即暴露被污染的检查点。 StripWake 将干净监督的完整令牌视图与目标监督的随机压缩视图配对，并与冻结的良性教师对齐早期视觉注意力以保持干净效用。
