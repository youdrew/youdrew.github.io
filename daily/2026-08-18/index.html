AWS 发布 aws-agents-pay 插件，将开源智能体框架 OpenClaw 与 Amazon Bedrock AgentCore 的支付能力及 x402 协议打通，使 AI 智能体能够在预设预算和人类审批的前提下，自动调用加密钱包，为付费 API、MCP 服务器及网页内容等数字资源完成链上微支付，目前交易在测试网上进行。x402 是一种基于 HTTP 402 状态码的链上支付协议，原本用于解决机器对机器的付费内容结算问题；AgentCore 则是 AWS 在 re:Invent 2025 上推出的智能体运行时服务，承担身份、状态与工具调用等基础设施职责。两者的结合意味着 AWS 不再只提供模型与编排能力，而是把支付通道、预算控制和审批流程一并嵌入智能体执行链路：开发者只需在 OpenClaw 配置支出上限和授权条件，智能体在遇到付费 API 或付费网页时，便可自主完成 402 挑战、签名并结算，调用链与资金流向可全程审计。这把智能体从单纯的“内容消费者”推向可独立完成经济行为的“代理参与者”，为后续数据采购、模型微调按需付费、自动化研究等场景提供了底座，也意味着云厂商正在把链上结算纳入智能体商业化的标准栈。

09Google Research

智能手机图像可绕过BMI评估心脏代谢风险

Google Research 团队近期发表了一项研究，提出利用智能手机拍摄的图像来评估心血管代谢（cardiometabolic）健康风险，目的是绕开传统体质指数（BMI）等指标的局限。BMI 仅基于身高与体重的比值，无法区分脂肪与肌肉，也无法反映脂肪在体内的分布，因而在评估真实健康风险时常出现偏差。研究人员开发的模型通过分析用户自拍图像，结合面部、身体轮廓以及皮肤特征等可见信息，并配合用户自报的少量元数据（例如年龄与性别），来估算腰围、体脂率等关键身体组成指标，并进一步预测心血管疾病、糖尿病等相关风险。早期结果显示，该模型在多项心血管代谢风险预测任务上的表现优于仅依赖 BMI 的基线方法，且在跨人群测试中保持了一定的泛化能力。这一思路的意义在于，它把智能手机摄像头转变为低成本、可大规模普及的健康筛查入口，尤其适用于医疗资源有限的地区或难以定期体检的人群，有望推动从单一指标向更精准、个体化的代谢健康评估转变。同时，研究者也强调该工具并非医学诊断手段，结果仍需结合临床检查进一步确认。
