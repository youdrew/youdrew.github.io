06Hugging Face

同一集群，GPU利用率再涨33，靠的是调度顺序

Hugging Face 在其工程博客中分享了一项针对大模型推理基础设施的调度优化实践：在不更换硬件、不增加 GPU 集群规模的前提下，仅通过调整推理请求的调度顺序，就将同一集群的 GPU 平均利用率进一步提升了约 33 个百分点。背景是，当前主流大模型在线推理服务普遍面临 GPU 利用率偏低、单位算力吞吐受限的痛点，硬件扩容成本高昂且周期长，因此软件层面的"零成本"优化空间备受关注。此次 Hugging Face 没有依赖新的推理引擎或模型压缩手段，而是从请求调度策略入手，将原本顺序或简单排队处理的推理任务按一定规则重新排序，例如结合输入长度、预估计算量或上下文特征进行匹配，使 GPU 的计算与显存占用更趋平稳，从而减少空闲气泡和资源争抢。关键细节在于，该方案可直接落地于既有生产集群，无需额外算力投入即获得约三分之一的利用率提升，意味着等效吞吐量与单位请求成本均获得同比例改善。对于自托管开源模型推理服务或面临推理成本压力的团队而言，这种以调度顺序为核心的工程优化提供了一条低门槛、可复用的降本增效路径。

07arXiv

BATON框架：用LLM智能体协调长时程机器人操作

长时程机器人操作任务通常需要将多个接触密集型子技能串联执行，虽然现有的视觉-语言-动作（VLA）模型在单项技能上表现优异，但在长链条任务中误差会逐级累积，并且子任务之间存在隐性约束关系，导致整体成功率显著下降。已有研究尝试冻结VLA权重，改用大语言模型智能体在语言层面进行高层规划，在自由空间阶段调用解析运动原语，仅在接触密集阶段调用VLA，并将适应信息以语言形式写入记忆，但这种方案在长时程场景中仍面临两重失败：一是智能体的能力来源于对整体任务的全局理解，简单的语言规划难以有效调度复杂动作；二是LLM推理带来的延迟使系统难以满足实时性要求。为此，论文提出BATON框架，通过增强LLM智能体的任务级认知能力并优化推理延迟，在保持VLA原有技能的同时实现更稳健的多阶段接触密集任务执行。实验结果表明，该方法在多阶段接触密集任务上的成功率显著优于直接以链式方式调用VLA的基线，验证了显式语言规划与按需调用结合的有效性，对推动长时程机器人操作在真实场景中的落地具有参考价值。

08arXiv

AutoSR：通过搜索研究状态实现自动化符号回归

AutoSR 是首个完整实现"研究空间符号回归"框架的全自动系统，由研究者在 arXiv 上提出，旨在解决符号回归中长期被忽视的可信度问题。传统符号回归通常只在孤立方程空间中搜索，以数值拟合优度和表达式语法复杂度作为主要评判标准，但在有限且含噪声的数据下，多个表达式可能拟合效果接近，却在观测范围之外表现出截然不同的行为，这意味着仅凭拟合分数无法判断其科学合理性。AutoSR 的核心思路是将搜索对象从单一公式扩展为持续性的科学研究轨迹：在更大的"研究空间"中持续探索，多次尝试不同的函数形式、变量组合与变换方式，并保留每次实验的设定与发现作为上下文，使后续搜索能够继承前序成果，而非仅留下最终公式和得分。这种类比科研过程的迭代机制，使得 AutoSR 能够生成在观测区间内外均表现一致、且具备物理可解释性的解析表达式。该系统的意义在于把符号回归从"拟合工具"推向"自动科学推理"的范式，凸显了科学可信度不能脱离研究过程单独衡量。
