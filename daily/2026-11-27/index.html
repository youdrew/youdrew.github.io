01AI Hot（卡兹克）Dragos称MiniMax会打开用户私有链接

据美国安全公司 Dragos 称，MiniMax 在用户要求不存储数据的情况下，仍从用户提示词中收集并打开了私人链接。 Dragos 在发送给众多 AI 服务的近200万条提示词中埋设了陷阱链接和虚假登录页面，以检查提供商是否秘密读取或传递客户数据。 据 Dragos 调查，只有到达 MiniMax 服务器的提示词中的链接在数天后被不明第三方打开，即使用户已要求不存储其数据。 其中一个链接24天后出现在字节跳动飞书的一场聊天中，北京和上海的3台台式机和3部手机在2分钟内打开了它；研究人员认为这更像有人分享该链接，而非自动化扫描器所为。 在链接抓取似乎于10月22日停止后，一个 git 客户端试图克隆发往 MiniMax 的提示词中提到的私有代码仓库，但目前不清楚是谁运行该客户端，也不清楚是否有代码被取走。 MiniMax 表示，其安全系统收集链接并自动打开部分链接以检查威胁；该表示同时称其未保留完整对话、已删除存储的地址，并未发现对话流向第三方的证据。 Dragos 研究人员观察到来自莫斯科地区、涉及这些链接的异常活动，但证据并未显示这些链接是在俄罗斯打开的。 Atlas Cloud 已停止将请求转发给 MiniMax，并告知 M3、M2.7 和 M3.1 Flash 用户将密钥视为已泄露；OpenRouter 移除了3家提供商并收紧了数据隐私规则。

03AI Hot（卡兹克）Google 强制 AI Agent 走 Workspace MCP 服务器，Gmail 服务器不能发邮件

Google 于 11 月 24 日将八个 Workspace MCP 服务器正式开放，并在 API 条款中新增条款，要求自 2027 年 2 月 1 日起由 AI Agent 驱动的工具必须通过这些服务器访问 Gmail、Drive 等 Workspace 服务，直接调用 REST API 将按 Standard 级配额受限。 自2027年2月1日起，任何“由 AI 智能体驱动或本身即为 AI 智能体”的工具，都必须通过这些服务器访问 Gmail、Drive、Calendar 以及 Workspace 的其他服务。 这些工具确实存在，但 Google 的配额页面写明它们“需要合作伙伴权限，尚未普遍开放”。 当 GWS 访问工具本身是 AI 智能体，或由 AI 智能体、AI 运行框架、AI 模型或使用 AI 模型的服务驱动时，该工具必须使用 Google MCP。 自同一天起，直接调用 REST API 的智能体一律按标准层级配额处理，无论项目付费购买了哪个层级。 Workspace 数据只能“用于完成用户授权的当前任务”，并且必须在用户断开连接时删除。 Google 没有说明谁有资格获得合作伙伴权限，也没有说明仅限合作伙伴的 Gmail 工具何时向所有人开放。 截止日期前创建且未及时标记的客户端将永久保持非智能体状态，因此所有者必须创建新的客户端。 具有域范围委派的服务账号无法设置智能体标志。 Apps Script 的内置 OAuth 客户端同样无法标记为智能体。 调用 MCP 服务器的脚本需要自定义客户端，而不调用 MCP 服务器的脚本不受影响。 其 README 现在将智能体用途指向 Google 新的官方 CLI gwscli，后者提供“一组为智能体精心设计的命令”，并且需要启用 MCP 服务。 付费的 Scaled 层级将于 2027 年 4 月 1 日起对 Gmail、Calendar 和 Drive 开始计费。 Google 尚未公布按请求计费的价格。 策略检查、数据边界和人工确认必须嵌入请求路径之中。 仅限合作伙伴使用的工具以及对嵌入的 30 天上限，都体现了这种控制在实践中如何运作。

04IT之家小米汽车世界模型2.0发布并落地业务

IT之家 11 月 27 日消息，小米汽车今日正式发布 Xiaomi Auto World Model 2.0（小米汽车世界模型 2.0）。 官方称小米汽车世界模型 2.0 进一步将多视角视频生成、物理交互建模、三维场景重建与动作建模连接起来，为辅助驾驶和具身智能统一因果世界模型带来新的范式。 据介绍，模型支持 1—7 路摄像头视角 ，训练语料规模达到 1,260 万段视频片段 ，并展示了从辅助驾驶、机器人场景生成，到闭环仿真与 World Action Model 的多项结果，在多个主流基准测试中全面取得 SOTA，并已在小米汽车合成数据、仿真测试等核心场景完成业务落地应用。 在 PAI-Bench-G 评测中，世界模型 2.0 的驾驶视频生成质量评分为 78.0 ，机器人视频生成质量评分为 77.1 ，均为项目主页所列对比方法中的最高分。 在感知理解任务上，世界模型 2.0 同样获得对比方法中最佳的指标结果。相比于前 SOTA 方法 VGGT-World，世界模型 2.0 在不同的数据序列上均取得最优结果，说明它不只在特定的数据序列上表现好，对其他数据序列也有很强的泛化能力。 在闭环训练任务中，使用世界模型 2.0 作为策略模型的世界模型仿真器，通过对策略模型预测的动作序列进行实际推演与奖励反馈，可以大幅提升策略模型的各项安全指标。 广告声明：文内含有的对外跳转链接（包括不限于超链接、二维码、口令等形式），用于传递更多信息，节省甄选时间，结果仅供参考，IT之家包含外链的文章均包含本声明。

arXiv无示范强化学习驱动K1人形机器人滑板

论文提出一种不依赖示范等先验数据的深度强化学习框架，使K1人形机器人等机器人通过无模型学习掌握滑板。 该方法将任务奖励与利用阻断终止机制结合，并限制机器人行为，包括板脚脱离、双脚站立、过度扭转、身体与滑板分离及滑板运动不稳定。 相关约束在训练过程中的出现频率变化，形成从站立控制到持续机器人—滑板运动的隐式进阶过程。 当前人形机器人滑板方法通常需要人工示范，或使用需要系统辨识的解析转向模型。 人形机器人运动研究已在行走和奔跑方面快速发展，但机器人需要与被动外部物体协调身体的对象介导运动仍然困难。 滑板是一项具有挑战性的任务，需要同时与地面和被动但可移动的平台交互以实现向前运动。
