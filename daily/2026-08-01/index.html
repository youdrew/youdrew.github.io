OpenAI Astra以约2000美元攻克10项数学难题

OpenAI 使用其尚未公开的下一代模型 Astra 内部版本，在数学与理论计算机科学领域一次性取得 10 项重要进展，研究方向涵盖非 sofic 群的存在性证明、Connes 嵌入问题与刚性猜想、von Neumann 代数、高维球堆积的最优上界以及电路复杂度下界等长期悬而未决的难题。按 Sol API 计价，整轮研究的人机算力支出约 2000 美元。OpenAI 已将全部 10 项证明的完整文本公开，同时附带 Lean 形式化验证证书以及模型的思维链推导过程，便于学术界逐行复核。这一进展的特殊意义在于：它不再局限于让模型解答孤立习题，而是在产出形式化、可验证的新定理，并以端到端的方式串联猜想陈述、构造证明与机器校验，表明大模型在深度数学推理上的能力已具备介入前沿纯数学研究的可行性，同时其单条研究成本远低于传统数学家数月乃至数年的投入，也对学术生产方式和 AI for Math 的走向提出了新的参照。

无状态 MCP 重新点燃关注，Simon 推出配套工具

MCP 2.0（2026-07-28 规范）的发布让 Model Context Protocol 重新成为关注焦点，这是该协议自 Anthropic 于 2024 年 11 月推出以来最重大的一次更新。Model Context Protocol 是由 Anthropic 提出的一套标准化接口协议，用于向基于大语言模型的 Agent 框架暴露外部工具；2025 年期间它曾迎来一轮关注高峰，随后被 Skills 等其他机制部分掩盖。此次规范更新回归"无状态"设计，被作者称为"无状态 MCP 日"，迅速重新点燃了开发者社区的研究热情。围绕这一版本，Simon Willison 推出了两款配套工具：mcp-explorer 用于浏览和探索可用的 MCP 工具资源，datasette-mcp 则将 Datasette 项目接入 MCP 生态，使大模型能够以标准化方式直接查询数据集。由于 MCP 已成为事实上的工具暴露标准协议，本次更新和配套工具的涌现，对 LLM Agent 生态、可观测性以及开放数据接入都具有积极意义。

10AI Hot（卡兹克） ＋1

smevals：跨模型的小型评测套件工具

Simon Willison 长期以独立博客形式追踪并评测各类大语言模型，此次他与 Prime Radiant 实验室合作推出 smevals，是他个人评测方法论的第三次迭代。该工具聚焦于解决模型横向对比中的两个痛点：一是小型、私有评测套件的跨模型复用，二是评测运行与打分的耦合问题。使用者只需执行 uvx smevals run，即可对包括 gpt-5.5、claude-opus-4.6 等在内的多个模型批量运行同一套评测，并将执行过程与结果打分拆分为独立步骤，最终输出一份静态 HTML 报告，便于分享与归档。由于采用 uvx 分发，smevals 无需复杂环境配置即可运行，显著降低了研究者和工程师搭建自定义评测流水线的门槛。其意义在于：随着闭源模型在公开基准上的分数日趋接近且存在过拟合风险，越来越多从业者倾向于构建专属小型评测集，而 smevals 为这类私有基准的横向对比、可复现性以及长期追踪提供了一套轻量化、工程化的基础设施。
