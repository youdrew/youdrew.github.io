02OpenAI ＋1

OpenAI 推出极速模式：GPT-5.6 Sol 提速 14 倍

OpenAI 在其 API 服务体系中新增了名为 Ultrafast 的极速服务层级，由晶圆级 AI 芯片公司 Cerebras 提供底层算力支持。该模式专为 GPT-5.6 Sol 模型设计，可将其推理速度提升至最高 14 倍，文本输出速率达到每秒 750 tokens，相当于在不到 1.4 秒的时间内即可生成一千字的文本内容。这一量级的延迟和吞吐表现，使原本受限于响应速度的实时交互场景成为可能，包括对话式 AI 代理的即时反馈、代码补全的类 IDE 体验、低延迟语音对话系统以及高频金融信息处理等对时延敏感的应用。值得注意的是，GPT-5.6 Sol 本身即为 OpenAI 面向高速推理场景优化的轻量化模型版本，而 Cerebras 的晶圆级处理器以片上大内存和极高内存带宽见长，二者结合将模型权重尽可能保留在处理器内部，显著减少了数据搬运所造成的等待时间。此次推出 Ultrafast 服务层级，意味着 OpenAI 正在 API 产品线中分化出针对不同性能优先级与成本结构的细分选项，为开发者提供了在标准云端推理与极致速度之间进行取舍的新空间，同时也进一步加剧了推理芯片市场的竞争格局。

08量子位

Claude一举扫清2000阶以下哈达玛矩阵！AI开始清空数学待解列表

Anthropic 旗下大模型 Claude 在纯数学领域取得重要进展：成功构造出所有 2000 阶以下的哈达玛矩阵，扫清了这一长期悬而未决的组合构造问题中阶数低于 2000 的全部实例。哈达玛矩阵是一类元素仅为 +1 与 −1、且行向量两两正交的方阵，其存在性与具体构造是离散数学与组合设计中的经典难题，多个阶数的构造长期缺失。Claude 的工作意味着，对每个不超过 2000 的整数阶数 n，只要 n 满足哈达玛矩阵存在的必要条件（即 n=1、2 或 n≡0 mod 4），模型都已给出显式构造，相关结果以可验证的数学对象形式产出，而非仅停留在解题描述层面。这表明现代大模型已能在纯理论数学的开放式问题上完成从证明存在性到给出具体实例的完整链路，把数学家手中数十年的待办列表逐项勾掉。此类能力来自模型在形式化数学推理、定理证明与构造性计算上的综合提升，意味着 AI 正从辅助验证走向主动探索未知，可能改变纯数学研究的协作方式与节奏，但目前成果仍集中于可计算、可枚举的具体构造问题，更高阶与更抽象的开放猜想仍是下一步需要攻克的目标。

10Apple 机器学习

利用低影响数据点实现近似零成本的机器遗忘

随着数据隐私监管趋严，从已训练模型中精准删除特定数据点成为机器学习领域的重要课题。现有"机器遗忘"方法普遍将遗忘集中所有数据点一视同仁，对每一个样本都执行完整的重新训练或参数调整流程，计算开销巨大。该研究质疑这一通行做法：并非所有需要"删除"的数据点都对模型学习产生实质影响。通过对影响函数进行跨任务对比分析，研究团队在语言与视觉任务上识别出多批对模型输出影响可忽略的训练样本，并证明对这些低影响数据点跳过传统遗忘流程，模型行为几乎不发生变化，从而将遗忘操作的成本压缩到接近零水平。这一发现改变了机器遗忘以"逐点处理"为主的范式，提供了一种基于影响度排序的筛选式高效删除思路：在保证遗忘效果的同时显著减少计算量，使大规模模型的数据隐私合规删除更具可行性，对推动隐私保护机器学习在工业场景中的落地具有现实意义。
