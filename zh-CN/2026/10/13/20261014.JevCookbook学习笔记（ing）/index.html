从一次类型化判断开始，学会设计输入、定义问题，并用程序处理结果。先完成第 1、2、3 章，再挑一个与自己需求有关的实战配方。这是教程推荐的学习主线。

课程入口：在线课程 · GitHub 仓库 · Notebook 运行说明

第一章 认识 Jev

课程入口：第一章导读 · 入门 Notebook

一句话：Jev 是 TypeSafe 的旗舰模型，也是第一个「System One」（挪用《思考，快与慢》的系统一概念，来强调这种快速地直觉的判断）模型——输入是状态（state）加一组类型化的问题（questions），输出是类型化的答案加概率分布。没有文本生成，也没有解析。
传统 LLM 为人类阅读写文本；当代码需要做判断时，就得把生成的文字再解析回程序可依赖的形式——这一步既慢又脆。
Jev 直接跳过这两步：像 LLM 一样读懂自然语言，但只返回你问的那几个数。

与 LLM 的区别（官方对比）

维度 聊天大模型 Jev（System One）
训练目标 生成讨人喜欢的回复（RLHF） 校准决策（RLCD）：概率对齐真实结果
输出 一段自由文本 类型化取值 + 概率分布（由你的问题定义）
会做什么 写作、代码、解释推理 只做判断；不写回复、不解释推理
适合谁消费 人 程序：分支、排序、路由

概念速查

先记住这条流程：state 提供证据 → 问题定义答案范围 → 模型返回判断与概率 → 代码决定动作。模型判断与程序动作的分工见第一章。

概念 先怎样理解 自己的练习问题
state 本次判断能够看到的事实与证据 哪些事实必须提供？
Noul 问「是否成立」，关注 P(true) 这条消息是否在请求退款？
Choice 问「选哪一项」，返回类别分布 消息属于咨询、退款还是投诉？
Score 问「程度多少」，在定义好的等级上判断 这条消息的紧急程度为哪个等级？

表中的消息问题是自拟练习；概念依据第二章。

阅读时留意三个区别：

  1. 有限选项判断与开放式生成：先想清楚任务的答案范围；要写长文或自由创作时，仍需要生成模型。第一章
  2. 概率、置信度与正确性：高置信度不能证明某次答案正确；校准需要跨样本比较预测与实际结果。第二章
  3. 离线示例与实时预测：修改输入后，静态示例响应不能作为模型新预测。要观察分布变化，需要实时调用并记录结果。运行说明
