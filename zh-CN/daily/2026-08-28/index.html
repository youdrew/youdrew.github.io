据外媒爆料，全球最大 AI 开源平台 Hugging Face 已与英伟达达成收购协议，作价约 129 亿美元，若交易完成，Hugging Face 将正式成为英伟达旗下资产，公司创始人、员工及早期股东将就此实现大规模财富变现。Hugging Face 成立于 2016 年，最初以聊天机器人起家，后转型为托管 Transformers、Datasets、Tokenizers 等核心开源库以及模型、数据集和 Spaces 应用的主要平台，目前托管模型数量已超过百万，是事实上的 AI 开源基础设施层，被开发者广泛视为"AI 时代的 GitHub"。收购方英伟达近年来持续从芯片公司向 AI 基础设施与平台公司转型，先后推出 Nemotron 系列模型、收购 Run:ai 等软件栈，若再将 Hugging Face 收入囊中，将在开源模型、分发渠道与开发者生态上完成关键拼图，直接挑战 AWS、Azure 等云厂商的模型托管服务。此举也意味着曾经立场相对中立的 AI 开源底座被纳入单一商业体麾下，社区围绕平台中立性、模型上架审核、数据合规以及未来定价策略的担忧随之升温，相关讨论已在 Hacker News 与 X 上迅速发酵。

08DeepMind

DeepMind 试点全球首个双盲 AI 评估

DeepMind 启动了一项被其称为全球首个双盲 AI 评估试点，将临床医学中沿用已久的双盲试验方法首次引入 AI 模型评测。在传统评估流程中，评估方通常预先知晓被测模型的来源、版本和归属，这种信息暴露容易引入主观偏好与品牌偏见。DeepMind 的试点通过中间机构对模型身份与评估方信息进行双向屏蔽，使评分者无法判断自己正在测试的是哪一家实验室的哪一个版本，目标则同样无法识别评估来源，以尽可能模拟真实部署环境下的反应。研究团队在试点中重点关注双盲机制在工程层面的可操作性，包括身份脱敏的处理流程、评测任务的标准化设计，以及如何防止知情人员泄露信息。DeepMind 表示，此次试点的意义不在于得出某个具体模型的优劣结论，而在于验证双盲范式在大语言模型安全与能力评测中是否可行，以及能否成为未来行业级评测的方法论基础。该项目也呼应了学界和监管层对 AI 评测客观性、可重复性不足的长期关切，若方法成熟，可能被纳入前沿模型发布前的标准审查流程，从而对模型厂商、第三方评测机构以及 AI 治理框架产生连锁影响。

09Claude Code ＋2

Claude Code v2.1.248 新增受限模式与代理缓存配置

Claude Code 发布 v2.1.248 版本，核心变化集中在企业级安全与代理可控性两个方向。最大亮点是新增 --restricted（CLAUDE_CODE_RESTRICTED=1）受限模式：开启后会自动移除内置的命令与代码执行类工具以及 WebFetch 工具，除非这些工具被显式列入 --tools 白名单；同时禁用 bypassPermissions 权限绕过选项，并忽略用户、项目和本地三级 settings 配置文件，只保留工作目录内的文件操作工具。该模式面向金融、医疗、政企等高合规场景，使管理员能够在不牺牲基础文件读写能力的前提下，强制收紧模型可触达的操作面，从源头降低提示词注入或误调用引发的越权风险。其次，代理层面引入 experimental.cacheTtl 配置项，可在 agent frontmatter 中以 "5m" 或 "1h" 设定每代理的提示缓存 TTL，作为无子代理 TTL 设置时的默认值，有助于在高频调用中复用上下文、降低成本并稳定响应延迟。运维侧则新增 claude self-hosted-runner 的 --client-label 参数及对应环境变量，便于自定义自托管 Runner 注册标签，便于多团队、多环境下的资源识别与配额管理。整体更新延续了 Claude Code 在企业落地中"默认更严、配置更细"的演进路径。
