04Machine Learning Street Talk ＋1NVIDIA世界模型让机器人在动作前预演结果

NVIDIA 研究科学家 Ming-Yu Liu 介绍其团队推出的 Cosmos 3 世界模型，核心目标是让机器人在真正执行动作之前，先在模型内部"预演"动作可能产生的结果，从而减少实物试错的成本与风险。该模型同时学习三种能力：前向动力学，即预测给定动作后环境会如何变化；反向动力学，即从观察到的状态变化反推导致该变化的控制动作；以及策略，即判断机器人下一步应当采取什么动作。研究论文显示，这三项任务并非彼此独立，而是存在明显的相互促进作用——前向与反向动力学的联合训练有助于策略学习，反过来策略信号又能进一步提升动力学预测精度。这一闭环结构使 Cosmos 3 能够在仿真与真实执行之间形成衔接，机器人可在虚拟推演中评估多种动作方案，再挑选最合适的动作部署到实体。其意义在于为通用机器人提供了一条可扩展的低成本训练与决策路径，尤其适用于真实环境中试错代价高、风险大的应用场景。

05arXiv冻结LLM内部路由机制替代上下文技能注入

针对大语言模型智能体日益庞大的技能库选择难题，当前主流部署方案依赖把全部技能元数据预加载进上下文窗口，这会分散模型注意力并限制技能库规模；检索式方案虽把选择移出上下文，却也让智能体失去了自主能力。来自arXiv的论文提出Gavel（Glance And Verdict from a frozen LLM），其核心发现是冻结的智能体大模型在前向传播中已天然携带路由信号，仅需两个轻量级线性映射就能将其读取出来，整个过程无需在上下文中预填任何技能描述文本。该方法在保持模型参数完全冻结、避免破坏智能体既有能力的前提下，解除了上下文长度对技能库规模的硬性约束，同时绕开检索式方案削弱模型能力的副作用，让路由效率与可扩展性兼得。这为构建可承载成千上万技能、又能保留端到端推理能力的LLM智能体提供了一条新路径，对推动智能体架构从检索增强走向原生内部信号利用具有方法论意义。

06AWS 机器学习Amazon Bedrock 提示缓存可降低输入成本最高 90%

AWS 发布关于 Amazon Bedrock 提示缓存功能的实战指南，重点演示如何通过 Converse API 在六种典型场景中复用已缓存的上下文，从而降低重复输入带来的 token 费用，最高可节省 90% 的输入成本。指南覆盖的具体场景包括：在多轮对话的消息内容中缓存历史文本、在系统提示中持久保存角色与规则定义、在工具定义中复用函数 schema 以避免每次请求重传、设置混合 TTL 以平衡缓存命中率与时效性、通过键值命名实现多租户间的缓存隔离，以及在 LangChain 框架下集成该能力。整个机制的核心在于识别那些在多次推理调用中保持不变的前缀内容，并由 Bedrock 在服务端进行透明缓存，使开发者在不改动模型的前提下显著压低长上下文应用的单位调用成本。对于在生产环境中频繁附带系统提示、工具列表或长文档片段的生成式 AI 工作负载，这一能力意味着在延迟、吞吐和账单层面都能获得可观的优化空间，同时也为多租户 SaaS 场景下的成本可控性提供了更直接的工程抓手。
