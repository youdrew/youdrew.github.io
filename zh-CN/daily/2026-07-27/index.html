俄罗斯为何无法复制美国帝国

这段视频是对谈节目，主持人 Dwarkesh Patel 邀请历史与战略学者 Sarah Paine 深入分析俄罗斯为何在结构上无法复制美国的全球帝国模式。Paine 从地缘、历史与制度三个层面展开对比：美国得以建立全球性海权帝国，依赖于其两面临洋的地理隔绝、两次世界大战中"坐山观虎斗"后介入的独特时机、英语国家联盟体系，以及将全球经济秩序作为权力延伸的制度能力；而俄罗斯的核心约束在于其横跨欧亚的陆权地理使其不得不维持漫长的陆上防线，缺少可制衡的海洋通道，历史上多次因同时面对多线威胁而被消耗。Paine 进一步指出，帝国扩张需要持续的制度创新与盟友网络吸纳能力，美国通过马歇尔计划、北约与战后多边贸易体系完成了这一过程，俄罗斯则始终依赖直接控制与安全胁迫，缺乏将边缘地区转化为有机经济体的能力，因此其影响力更多体现为区域性威慑而非全球秩序供给。这一分析的核心意义在于揭示大国兴衰并非单纯取决于军事实力，而是受制于地理位置、战略时机与制度弹性的深层组合，俄罗斯的先天约束使其难以突破区域性大国的天花板，而美国的帝国模式本质上是历史窗口与地理禀赋的产物，无法被简单移植。

09Simon Willison

深入调查：代币转售市场背后的中继产业链与欺诈乱象

AI API 大模型 token 折扣转售已形成一个灰色产业链，主要集中在中国市场。调查显示，转售商通过自建代理服务（多基于开源软件 one-api 等），聚合来自不同来源的 API key，以显著低于官方定价的价格向用户提供大模型访问权限。其折扣来源主要包括三类：滥用平台免费试用额度、借助未受保护的客服机器人或代理端点进行中转套利，以及直接使用盗刷的信用卡或发起拒付攻击。白嫖试用和拒付攻击意味着部分成本由模型厂商实际承担，导致 API 计费系统出现坏账。这类"中继"服务的规模化运营，暴露出主流大模型平台在身份验证、密钥管理、用量监控等环节的防护薄弱，也对按量计费模式与代理场景下的安全设计提出了新的警示。
