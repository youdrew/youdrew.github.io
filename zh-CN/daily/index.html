03Ars Technica研究称AI路由链泄露敏感数据

06arXiv · 视觉计算预训练视觉模型以二维平面编码相对视角

研究发现，相对视角α在预训练视觉模型的隐藏空间中以跨场景共享的二维平面编码，两个物体的特征差沿该平面追踪(cosα, sinα)。 该平面的方向在光照、颜色、地面和物体形状变化时保持不变。 在一组相机路径上拟合的读取器能够外推到其范围之外的相机位置，而测量物体与阴影几何的解码器在该范围外失效。 在扩散Transformer PixArt-α中，该平面在单个模块处突然形成，并将方向信息传递至后续模块；编辑该平面会改变物体，而非生成的视点。 实验在渲染场景中进行：相机移动时两个物体的中心像素保持固定，因此透视、阴影和光照发生变化，但投影布局不变。

OpenAI称其对抗性蒸馏防护结合了对抗测试、模型训练、分类器和 API 级保护，并对协同提取模型能力的尝试进行调查。 OpenAI称其防护措施在请求级和活动级展开：请求级利用模型行为、分类器检查和 API 控制限制推理轨迹提取，活动级则寻找请求级和账户级信号中的协同提取模式。 OpenAI表示，其在平台上看到了多起未经授权的对抗性蒸馏活动，并已通过每周执法行动处理这些活动；行动规模从数千到数万个账户不等，今年夏季执行率显著上升。 OpenAI称，网络安全蒸馏结果表明，保护推理轨迹可以限制网络能力转移，即使被蒸馏的底层任务属于其使用政策允许的范围。 OpenAI表示，将继续与研究人员、开发者和合作伙伴合作，分享其对新兴攻击和有效防护措施的认识。 OpenAI称将继续研究在不同学生模型和蒸馏训练方案之间会有多少额外能力发生转移。 在使用最大推理预算进行强化学习后，两项基准中由精确推理轨迹训练的学生模型得分仍高于由推理摘要训练的学生模型；由摘要训练的学生模型在较低预算下得分更高。 在针对 GPT‑6 Astra 和 GPT‑6.2 Astra 的自适应黑盒红队测试中，攻击成功率按 6 个攻击者模型汇总，攻击成功率越低越好。 OpenAI称，其目标是限制蒸馏者能够获取的数据数量和价值、提高蒸馏活动的成本，并缩短应对新攻击所需的响应时间。
