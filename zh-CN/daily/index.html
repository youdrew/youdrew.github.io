01微软研究院人类主导AI协作证明KLS猜想

微软研究院机器学习与优化组的 Xinzhi Zhang 与一名合作者证明了 Kannan–Lovász–Simonovits（KLS）猜想，证明表明该关系具有不随形状维度变化的固定界限。 研究人员在人类主导的 AI 代理研究流程中探索了 100 多种候选方法，其中许多涉及高阶张量的大量计算，并由此形成了最终证明的新数学判据。 作者证明，每一阶段引入的小误差衰减得足够快，其总和保持在一个与维度无关的普适常数以内，从而消除了对维度的依赖。 在作者发布完整证明的同一天，另一组专家发布了独立开发的完整证明，将其建立于微软论文第一版的研究结果之上；第三份证明也在同日单独出现并采用了密切相关的思路。 AI 工具协助探索候选方案、完成详细推导、准备论文并执行内部证明检查；研究人员确定数学方向、选择有前景的想法、将其组织成最终论证并验证证明。 2026年10月1日论文版本将维度依赖降至迭代对数，但该函数增长虽极慢却仍随维度增长，因此尚未完全解决猜想。 最终步骤是重复整个递归改进过程，而不是仅应用一次。 独立证明之所以是数学领域最强的验证形式之一，是因为它们表明结果不依赖单一推理链条。 作者已缩短证明并在 Lean 中验证精简后的论证，计划在最终审查后发布两者。

04AI Hot（卡兹克）OpenAI发布低延迟Decisions API

OpenAI 正式全面推出 Decisions API；该 API 基于 GPT-6 Luna 构建，面向答案有界的问题，通过 Responses API 使用 GPT-6 Luna 时速度最高快 10 倍。 自公开测试版以来，OpenAI 为 Decisions API 新增了原生 GPT-Live 集成、针对重复使用上下文的提示缓存，以及美国和欧盟的推理驻留。 开发者可以向 Decisions API 传入原生 JSON 输入、在问题指令中包含图像，并且每个请求最多可提出 400 个问题，是此前上限的两倍。 Decisions API 支持 predicate、choice 和 score 三种答案类型，分别返回概率、预定义选项及概率和置信度、或各等级索引的概率加权平均值。 Decisions API 现已通过专用 Decisions 端点正式提供，并支持 GPT-6 Luna。 Decisions API 的费用为每百万输入 token 0.10 美元，缓存输入费用为每百万 token 0.01 美元；开发者只需为输入 token 付费，没有输出 token 费用。 Decisions API 的区域处理可在美国和欧盟使用，符合条件的客户还可使用零数据保留。 Decisions API 支持文本、图像和原生 JSON 形式的上下文。 Decisions API 与 GPT-Live 原生集成，可用于实时对话中的决策。 GPT-Live 演示中的虚拟形象表情面板可点击一张脸进行预览。

06arXiv · 视觉计算SolarRenderer少步生成结构引导视频

SolarRenderer使用两个轻量LoRA适配冻结的MiniMax-H3 33B骨干模型，生成受结构条件控制的视频。 游戏引擎和编程智能体可以规定场景的布局、运动和镜头，但将这些粗略结构转化为逼真视频，需要渲染器遵循结构并补全其未规定的外观。 结构视频通过骨干模型原生的参考路径输入，不使用类型标识且仅以纯文本描述，使单一控制LoRA能够适配任意结构表示。 该方法从预训练的四步LoRA出发，通过结构引导分布匹配实现四步渲染，比50步采样快12.3倍，同时保留所学控制能力；块因果变体还将该设计扩展到流式渲染，并以实时速度渲染768p视频。 实验在分布内测试集和包含16种结构表示的泛化基准上进行了评估，摘要称SolarRenderer在两者上均取得当前最佳结果，并泛化到包括姿态骨架、绘画和点云在内的11种未见表示。
