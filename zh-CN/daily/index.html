10IT之家英特尔推出至强推理微服务，自动检测硬件并配置 vLLM

英特尔于 10 月 14 日宣布推出 Intel Inference Microservices 服务，是一套面向大语言模型推理的容器化微服务方案，目标是在已有的至强处理器上直接获得经过调优的模型推理能力，无需再花费数天时间进行手动硬件优化。 首批版本基于 vLLM 引擎，支持 BF16 精度，可在 Docker 或 Kubernetes 1.24 及以上环境中运行，硬件要求为第四代、第五代或第六代英特尔至强处理器，建议配置 32GB 内存。 容器启动时自动检测处理器代数、分配到的核心数量、NUMA 节点数量以及处理器内置的加速器；其中加速器包括用于矩阵乘法的英特尔高级矩阵扩展和用于周边计算的 AVX-512、AVX2 及 VNNI 向量扩展。 微服务以容器形式提供 OpenAI 兼容 API 暴露在已知端口上，启动时若运行特定模型镜像且主机未被识别，会在启动时报错而不是以未调优状态运行；基础镜像则默认启用配置回退。 今年 9 月，英特尔开发者页面已介绍过 Intel AI for Enterprise Inference，一套面向至强处理器的开源 LLM 服务栈，同样基于 vLLM 架构；此次发布的推理微服务可视为将这一能力产品化、容器化。 硬件层面，参数会因迁移到另一代芯片而需要重新调整。 微服务接口方面，英特尔调优后的容器仍然是一个标准的 OpenAI 兼容端点，而不是必须采用的 SDK。 后续版本规划方面，英特尔计划在后续版本中增加 Helm Chart、Kubernetes Operator、更多推理引擎和精度支持。 能力支持范围方面，目前工具调用和结构化输出功能可作为 vLLM 的透传能力使用，但尚未被验证为正式支持的能力。
