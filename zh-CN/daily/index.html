01Agent智能体深度研究院ICLR 2026论文EvoTest：冻结模型的测试时进化学习框架

EvoTest 由新加坡国立大学团队发表于 ICLR 2026，针对当前 Agent 系统依赖大规模微调、成本高且难以持续迭代的痛点，提出一种测试时进化学习框架。其核心思路是冻结 backbone，不进行梯度更新，转而引入一个 Evolver 模块，依据每轮 Agent 产生的完整执行轨迹，动态改造 prompt、记忆库、超参数与工具调用流程，从而实现 Agent 系统的运行时自改进。配套地，论文构建了 J-TTL 评测基准，用于衡量任务级别的真实改进而非单步正确率；同时采用 UCB 机制，在探索新策略与复用历史成功策略之间取得平衡，缓解反复试错的成本。该方法的意义在于，把 Agent 能力提升从昂贵的预训练或微调阶段前移到部署之后，使冻结的基座模型也能随交互持续进化，为低成本、可迭代的智能体部署提供了一条新路径。

02DeepMindDeepMind发布AlphaGenome Atlas人类基因变异预测图谱

DeepMind发布了AlphaGenome Atlas，这是基于其AlphaGenome模型构建的大规模人类基因变异预测图谱，覆盖人类基因组中约90亿个单碱基DNA变异，可系统性预测任意单点突变对基因调控等关键分子过程的影响。AlphaGenome模型此前已能整合长程基因调控序列信息，对RNA剪接、基因表达、转录因子结合等多种分子表型进行高分辨率预测，而此次推出的Atlas则将这一能力扩展到全基因组尺度，为研究人员提供了一个可直接查询的统一参考资源。在传统湿实验中，逐一实验验证数十亿个变异的分子效应几乎不可行，而该图谱通过计算预测填补了这一空白，使科学家能够快速评估特定变异在调控层面的潜在功能意义。这一资源将有助于推动功能基因组学研究，尤其是在解析罕见变异致病性、识别非编码区功能元件以及支撑大规模人群基因组注释方面具有重要价值。

08Hugging FaceHugging Face研究：安全模型应拒答子主题而非整类话题

Hugging Face发布研究指出，现有AI安全对齐常以话题类别作为拒答边界，例如将“如何制造炸弹”相关问题整体标记为危险并拒绝回答。这种做法虽然便于部署，却容易将同一话题中的合法内容一并屏蔽，形成过度拒绝。研究建议采用更细粒度的安全判断：先识别请求涉及的具体子主题与潜在危害，再仅拒绝危险部分，同时允许知识解释、风险教育、历史讨论及非操作性信息等安全内容正常生成。该方法有望提升模型在安全边界上的精确度，减少不必要的审查和用户体验损失，并为安全分类、训练数据构造、红队测试及实际部署提供更具可操作性的对齐思路。
