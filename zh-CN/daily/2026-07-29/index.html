08GitHub Blog

GitHub发布npm与Actions供应链攻击防御措施

GitHub 近日汇总了过去数月在 npm 注册中心和 GitHub Actions 平台上针对供应链攻击所推出的一系列防御性更新，核心目标是破坏攻击者的常用技术并限制其一旦得手后的破坏范围。在 npm 侧，平台持续加大对恶意软件包、凭据窃取脚本以及依赖混淆等常见攻击向量的检测与下架力度，同时改进发布者身份验证流程，强化令牌管理以减少被劫持后批量投毒的风险；在 Actions 侧，重点收紧对第三方 GitHub Actions 的使用约束，包括限制未经审查的 Action 在拉取请求中自动获得敏感权限、加强对工作流中令牌和密钥的最小权限原则提示，并改进对 Action 发布链路的签名与验证机制。这些措施延续了 GitHub 在 2024 年因 tj-actions 等事件后逐步建立的安全加固路线，旨在把供应链安全的责任从被动的漏洞披露前移为主动的平台级拦截，对依赖开源生态进行构建和分发的开发者与组织而言，能显著降低被植入后门或凭据泄露的可能性，但也意味着维护者在发布和使用第三方包与 Action 时需更严格地遵循权限最小化和来源校验等实践。
